The `ds3231` switch platform exposes the [DS3231 real-time clock](/components/ds3231/) settings that map to a
simple on/off: the two alarm interrupt-enable bits and the 32 kHz output.

Set up the [`ds3231`](/components/ds3231/) hub (and the [I²C](/components/i2c/) bus it needs) first.

```yaml
# Example configuration entry
ds3231:
  id: ds3231_hub

switch:
  - platform: ds3231
    alarm_1:
      name: "RTC Alarm 1 Enabled"
    enable_32khz_output:
      name: "RTC 32 kHz Output"
```

## Configuration Variables

- **ds3231_id** (*Optional*, [ID](/guides/configuration-types#id)): The ID of the [`ds3231`](/components/ds3231/)
  hub to use when more than one is configured.
- **alarm_1** (*Optional*): Enables or disables alarm 1 via its interrupt-enable bit. Icon `mdi:alarm`,
  config entity category, restore mode disabled (the real state lives in the chip). See
  [Behavior](#behavior) below. All options from [Switch](/components/switch/#config-switch).
- **alarm_2** (*Optional*): As `alarm_1`, for alarm 2.
- **enable_32khz_output** (*Optional*): Turns the 32 kHz output on and off at runtime. When on, the chip
  drives a 32.768 kHz square wave on its dedicated `32K` pin. Set the boot state with the hub's
  [`enable_32khz_output`](/components/ds3231/#configuration-variables) option. Icon `mdi:sine-wave`, config
  entity category, restore mode disabled. All options from [Switch](/components/switch/#config-switch).

At least one of `alarm_1`, `alarm_2` or `enable_32khz_output` must be provided.

## Behavior

The `alarm_1` / `alarm_2` switches read and control the chip's alarm interrupt-enable bits:

- `ON` : The alarm is enabled. [`ds3231.set_alarm_1`](/components/ds3231/#ds3231-set_alarm_1-action) /
  [`ds3231.set_alarm_2`](/components/ds3231/#ds3231-set_alarm_2-action) turn the switch `ON` as a side effect.
- `OFF` : The alarm is disabled, but its programmed match time is kept. Turn the switch back `ON` to
  re-enable it without calling `ds3231.set_alarm_*` again.
- The [`ds3231.enable_alarm`](/components/ds3231/#ds3231-enable_alarm-action) and
  [`ds3231.disable_alarm`](/components/ds3231/#ds3231-disable_alarm-action) actions are the action forms of
  turning the switch on and off.
- [`ds3231.clear_alarm`](/components/ds3231/#ds3231-clear_alarm-action) only clears the "fired" flag; it does
  not change these switches.

The hub republishes the true chip state every `update_interval`, so the switch stays correct even if the
alarm is enabled or disabled by other means.
