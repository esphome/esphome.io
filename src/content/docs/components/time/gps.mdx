> [!WARNING]
> The `gps` time platform is deprecated and will be removed in 2027.6.0. Use the
> [geolocation time source](/components/time/geolocation/) instead.

You first need to set up the [GPS](/components/gps/) component.

```yaml
# Example configuration entry
time:
  - platform: gps
    id: gps_time
```

## Configuration variables

- All options from [Base Time Configuration](/components/time/#base_time_config).
