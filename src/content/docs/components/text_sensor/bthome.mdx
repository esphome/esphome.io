The `bthome` text sensor platform lets you receive string values broadcast by [BTHome v2](https://bthome.io/) Bluetooth Low Energy devices. The ESP32 acts as a passive BLE listener — it does not connect to the remote device, it simply receives its advertisements.

> [!WARNING]
> The BLE software stack on the ESP32 consumes a significant amount of RAM on the device.
>
> **Crashes are likely to occur** if you include too many additional components in your device's
> configuration. Memory-intensive components such as [Voice Assistant](/components/voice_assistant/) and other
> audio components are most likely to cause issues.

> [!NOTE]
> This platform requires the [BTHome](/components/bthome/) component to be configured with at least one `remote_devices` entry.

```yaml
# Example configuration entry
esp32_ble_tracker:

bthome:
  remote_devices:
    - mac_address: "AA:BB:CC:DD:EE:FF"
      id: my_sensor_device

text_sensor:
  - platform: bthome
    source_id: my_sensor_device
    type: text
    name: "Device Status"
```

## Configuration variables

- **source_id** (**Required**, [ID](/guides/configuration-types#id)): The ID of the remote device declared in the `bthome` component's `remote_devices` list.
- **type** (**Optional**, string): The BTHome text sensor type to receive, such as `text` or `raw`. Must be one of the [supported text sensor types](/components/bthome#supported-text-sensor-types). Type names are case-insensitive. Defaults to `text`.
- All other options from [Text Sensor](/components/text_sensor).

## Encrypted devices

To receive data from a device that uses BTHome encryption, add a `key` to the remote device entry:

```yaml
bthome:
  remote_devices:
    - mac_address: "AA:BB:CC:DD:EE:FF"
      id: my_sensor_device
      key: "0123456789ABCDEF0123456789ABCDEF"

text_sensor:
  - platform: bthome
    source_id: my_sensor_device
    type: text
    name: "Device Status"
```
