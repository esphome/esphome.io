The `ds3231` component provides support for the Maxim/Analog Devices DS3231 real-time clock (RTC). The DS3231
is a temperature-compensated RTC accurate to a few parts per million, and is found on inexpensive breakout
boards such as the ZS-042. In addition to keeping time it provides two programmable alarms, a temperature
sensor, a configurable square-wave output and a trim (aging offset) register.

<Image src="/images/ds3231.png" width={300} height={300} layout="constrained" alt="DS3231 RTC breakout board" />

This component is an I²C hub. It talks to the chip and exposes the individual features through separate
platforms:

| Feature | Description |
| ------- | ----------- |
| [`time`](/components/time/ds3231/) | use the RTC as a time source |
| [`sensor`](/components/sensor/ds3231/) | read the on-die temperature |
| [`binary_sensor`](/components/binary_sensor/ds3231/) | alarm-fired and oscillator-stopped flags |
| [`switch`](/components/switch/ds3231/) | arm the alarms, enable the 32 kHz output |
| [`select`](/components/select/ds3231/) | set the `INT/SQW` pin mode and square-wave frequency |
| [`number`](/components/number/ds3231/) | adjust the aging offset |

The [I²C](/components/i2c/) bus must be set up first.

```yaml
# Example configuration entry
i2c:
  sda: GPIOXX
  scl: GPIOXX

ds3231:
```

## Configuration Variables

- **id** (*Optional*, [ID](/guides/configuration-types#id)): The ID to use for referencing this hub from
  the platforms and actions listed below.
- **address** (*Optional*, int): The I²C address of the chip. Defaults to `0x68`.
- **square_wave_output** (*Optional*, enum): Drive a fixed-frequency square wave on the `INT/SQW` pin. One of
  `1Hz`, `1.024kHz`, `4.096kHz` or `8.192kHz`. When omitted, the pin is left available for the alarm interrupt.
  See [Square-Wave Output](#square-wave-output).
- **battery_backed_square_wave** (*Optional*, boolean): Keep the square wave running while the chip is on
  battery power. Requires `square_wave_output`. Defaults to `false`.
- **on_alarm_1** (*Optional*, [Automation](/automations)): Automation to run when alarm 1 fires. See
  [Alarms](#alarms).
- **on_alarm_2** (*Optional*, [Automation](/automations)): Automation to run when alarm 2 fires.
- **update_interval** (*Optional*, [Time](/guides/configuration-types#time)): How often to poll the alarm
  flags and the oscillator-stopped flag. Defaults to `30s`.
- **i2c_id** (*Optional*, [ID](/guides/configuration-types#id)): The ID of the [I²C](/components/i2c/) bus
  when using multiple buses.

Multiple DS3231 chips (on different addresses or buses) can be configured by giving each one its own entry
with a distinct `id`.

## Square-Wave Output

The `INT/SQW` pin can act either as an alarm interrupt or as a square-wave generator, but not both at once.

- If `square_wave_output` is set, the pin emits the selected frequency. This is useful for clocking external
  hardware or for confirming the chip is alive with a scope or LED.
- If `square_wave_output` is not set, the component puts the pin in alarm-interrupt mode at startup: it idles
  high and is pulled low by the chip while a programmed alarm's flag is set, then released when the flag is
  cleared.

Programming an alarm with the [`ds3231.set_alarm_1`](#ds3231-set_alarm_1-action) or
[`ds3231.set_alarm_2`](#ds3231-set_alarm_2-action) action switches the pin from square-wave mode to alarm
interrupt mode.

The pin can also be controlled at runtime from a [lambda](/automations/templates#config-lambda), with
`square_wave_output` acting as the startup default:

- `set_square_wave_output_enabled(true)` drives the square wave (at the current frequency, defaulting to the
  `square_wave_output` value or 1 Hz); `false` returns the pin to alarm-interrupt mode.
  `get_square_wave_output_enabled()` reads the mode back from the chip.
- `set_square_wave_frequency(...)` changes the frequency; `get_square_wave_frequency()` reads it back.

```cpp
using esphome::ds3231::DS3231SquareWaveFrequency;
id(ds3231_hub)->set_square_wave_frequency(DS3231SquareWaveFrequency::DS3231_SQUARE_WAVE_FREQUENCY_8192_HZ);
id(ds3231_hub)->set_square_wave_output_enabled(true);
```

The frequency values are `DS3231_SQUARE_WAVE_FREQUENCY_1_HZ`, `_1024_HZ`, `_4096_HZ` and `_8192_HZ`. Arming an
alarm still forces the pin back to interrupt mode.

The [`select`](/components/select/ds3231/) platform exposes both of these (pin mode and frequency) as entities
without writing a lambda.

## Alarms

The DS3231 has two independent alarms:

- **Alarm 1** has one-second resolution.
- **Alarm 2** has one-minute resolution and always fires at second `0`.

Alarms are programmed at runtime with the actions below; there is no alarm configuration on the hub itself.
Each alarm sets a "fired" flag in the chip when it matches. This component polls those flags every
`update_interval`, runs the matching `on_alarm_1` / `on_alarm_2` automation, updates the
[alarm binary sensors](/components/binary_sensor/ds3231/) and then clears the flag so the next match can be
detected.

An alarm stays armed after it fires. [`ds3231.clear_alarm`](#ds3231-clear_alarm-action) only clears the fired
flag, it does not disarm the alarm. To disarm an alarm (while keeping its programmed time so it can be
re-armed later), turn off its [`switch`](/components/switch/ds3231/).

The `on_alarm_1` / `on_alarm_2` triggers and the `alarm_1` / `alarm_2`
[binary sensors](/components/binary_sensor/ds3231/) only react while that alarm is enabled. Disarming an alarm
suppresses them without clearing its programmed time; a match that occurs while the alarm is disarmed is
ignored, and re-arming does not replay it.

> [!NOTE]
> Because the flags are polled, the automation runs up to `update_interval` after the alarm actually
> matched. Lower `update_interval` for tighter timing, or wire the `INT/SQW` pin to a
> [GPIO binary sensor](/components/binary_sensor/gpio/) to react immediately.

> [!NOTE]
> Since the component clears the alarm flags on every poll, the `INT/SQW` pin is only held low until the next
> poll (up to `update_interval`). That is enough to wake a sleeping ESP through that pin. If you need the
> hardware pulse held longer while the device is running, raise `update_interval`. The `on_alarm_1` /
> `on_alarm_2` automations fire either way.

<span id="ds3231-set_alarm_1-action"></span>

## `ds3231.set_alarm_1` Action

Program and arm alarm 1.

```yaml
on_...:
  - ds3231.set_alarm_1:
      id: ds3231_hub
      mode: MATCH_HOUR_MINUTE_SECOND
      hour: 7
      minute: 30
      second: 0
```

Configuration variables:

- **id** (**Required**, [ID](/guides/configuration-types#id)): The ID of the DS3231 hub.
- **mode** (**Required**, enum): Which fields must match for the alarm to fire:
  - `EVERY_SECOND`: fires once per second.
  - `MATCH_SECOND`: when `second` matches.
  - `MATCH_MINUTE_SECOND`: when `minute` and `second` match.
  - `MATCH_HOUR_MINUTE_SECOND`: when `hour`, `minute` and `second` match (once per day).
  - `MATCH_DAY_OF_MONTH`: additionally when `day_of_month` matches.
  - `MATCH_DAY_OF_WEEK`: additionally when `day_of_week` matches.
- **second** (*Optional*, int, [templatable](/automations/templates)): Second to match, `0` to
  `59`. Defaults to `0`.
- **minute** (*Optional*, int, [templatable](/automations/templates)): Minute to match, `0` to
  `59`. Defaults to `0`.
- **hour** (*Optional*, int, [templatable](/automations/templates)): Hour to match (24-hour),
  `0` to `23`. Defaults to `0`.
- **day_of_week** (*Optional*, int, [templatable](/automations/templates)): Day of week to
  match, `1` (Sunday) to `7` (Saturday). Only for `mode: MATCH_DAY_OF_WEEK`.
- **day_of_month** (*Optional*, int, [templatable](/automations/templates)): Day of month to
  match, `1` to `31`. Only for `mode: MATCH_DAY_OF_MONTH`.

`day_of_week` and `day_of_month` are mutually exclusive.

> [!NOTE]
> `day_of_week` follows ESPHome's convention (`1` = Sunday). This only lines up with the RTC's own
> day-of-week counter if the clock was set through the [`time`](/components/time/ds3231/) platform or the
> [`ds3231.write_time`](/components/time/ds3231/#ds3231-write_time-action) action, which is the normal path.

<span id="ds3231-set_alarm_2-action"></span>

## `ds3231.set_alarm_2` Action

Program and arm alarm 2. Identical to `ds3231.set_alarm_1` except that there is no `second` field and the
available modes are `EVERY_MINUTE`, `MATCH_MINUTE`, `MATCH_HOUR_MINUTE`, `MATCH_DAY_OF_MONTH` and
`MATCH_DAY_OF_WEEK`.

```yaml
on_...:
  - ds3231.set_alarm_2:
      id: ds3231_hub
      mode: MATCH_DAY_OF_WEEK
      day_of_week: 2  # Monday
      hour: 8
      minute: 0
```

<span id="ds3231-clear_alarm-action"></span>

## `ds3231.clear_alarm` Action

Clear a pending alarm's "fired" flag. This re-arms the flag for the next match; it does **not** disable the
alarm, turn off the alarm's [`switch`](/components/switch/ds3231/) for that.

```yaml
on_...:
  - ds3231.clear_alarm:
      id: ds3231_hub
      alarm: 1
```

Configuration variables:

- **id** (**Required**, [ID](/guides/configuration-types#id)): The ID of the DS3231 hub.
- **alarm** (**Required**, int): Which alarm to clear, `1` or `2`.

<span id="ds3231-force_temperature_conversion-action"></span>

## `ds3231.force_temperature_conversion` Action

Trigger an immediate temperature conversion instead of waiting for the chip's automatic 64-second cycle. The
result is also used to re-tune the oscillator.

```yaml
on_...:
  - ds3231.force_temperature_conversion: ds3231_hub
```

## Reading the Programmed Alarm

The hub exposes the alarm currently programmed into the chip so you can display it, for example in a
[template text sensor](/components/text_sensor/template/):

```yaml
text_sensor:
  - platform: template
    name: DS3231 Alarm 1
    lambda: |-
      char buf[40];
      if (!id(ds3231_hub)->describe_alarm_1(buf, sizeof(buf)))
        return {"not set"};
      return {buf};
```

`describe_alarm_1()` / `describe_alarm_2()` write a short summary into `buf` and return `false` (leaving `buf`
untouched) when the alarm registers can't be decoded, for example on a fresh chip whose alarm registers
were never written. The summaries read like:

- Alarm 1: `every second`, `every minute at :SS`, `every hour at MM:SS`, `daily at HH:MM:SS`,
  `day D at HH:MM:SS`, `weekday D at HH:MM:SS`
- Alarm 2: `every minute`, `every hour at MM:00`, `daily at HH:MM`, `day D at HH:MM`, `weekday D at HH:MM`

`weekday D` uses the same `1` = Sunday convention as the alarm actions. The programmed alarms are also printed
at startup in the component's `dump_config` output.

For structured access, `get_alarm_1(mode, spec)` / `get_alarm_2(mode, spec)` read the mode and the field
values (`DS3231AlarmSpec` has `second`, `minute`, `hour` and `day`) back from the chip. They return `false` on
a bus error or an unrecognized register pattern.

## Hardware Notes

- On common breakout boards (ZS-042 and similar) a separate AT24C32 EEPROM is fitted at address `0x57`. It is
  not used by this component but will show up in an [I²C scan](/components/i2c/).
- Setting an alarm repurposes the `INT/SQW` pin, so a configured square-wave output stops once an alarm is
  programmed.
- If the chip reports that its oscillator stopped (loss of both `VCC` and battery), the stored time is not
  trusted: the [`time`](/components/time/ds3231/) platform refuses to sync from it until a valid time is
  written back with [`ds3231.write_time`](/components/time/ds3231/#ds3231-write_time-action).

## Full Configuration Example

This example exercises every platform: the RTC is disciplined from [SNTP](/components/time/sntp/), and the
temperature, alarm state, `INT/SQW` pin mode, 32 kHz output and aging offset are all exposed. `INT/SQW` is
left as the alarm-interrupt line (no `square_wave_output`); the `select` can switch it to a square wave at
runtime. The [web server](/components/web_server/) `sorting_groups` keep the DS3231 entities together on the
dashboard.

The alarms are driven two ways. The *Set Alarm* buttons use the declarative
[`ds3231.set_alarm_1`](#ds3231-set_alarm_1-action) / [`ds3231.set_alarm_2`](#ds3231-set_alarm_2-action)
actions with fixed values. The *alarm builder* &mdash; template [numbers](/components/number/template/) and
[selects](/components/select/template/) for the mode and time fields plus an *Apply*
[button](/components/button/template/) &mdash; instead calls `id(ds3231_hub)->set_alarm_1(mode, spec)` from a
lambda, because the action's `mode` is not templatable and so cannot be driven from a runtime select.

```yaml
# Version 3 is required for sorting_groups.
web_server:
  version: 3
  port: 80
  sorting_groups:
    - id: ds3231_group
      name: DS3231
      sorting_weight: 10
    - id: ds3231_alarm_group
      name: DS3231 Alarms
      sorting_weight: 20
    # Input fields for composing an alarm. Nothing here touches the chip until
    # the matching "Apply" button is pressed.
    - id: ds3231_alarm1_builder_group
      name: DS3231 Alarm 1 Builder
      sorting_weight: 30
    - id: ds3231_alarm2_builder_group
      name: DS3231 Alarm 2 Builder
      sorting_weight: 40

# DS3231 breakouts (ZS-042 etc.) are typically at 0x68. GPIO8/GPIO9 are the
# ESP32-S3 default I2C pins and have no secondary function on the DevKitC-1.
i2c:
  - id: i2c_bus
    sda: GPIO8
    scl: GPIO9
    scan: true
    frequency: 400kHz

ds3231:
  - id: ds3231_hub
    i2c_id: i2c_bus
    address: 0x68
    # How often the alarm flags / oscillator-stop flag are polled.
    update_interval: 10s
    on_alarm_1:
      then:
        - logger.log: "DS3231 alarm 1 fired"
    on_alarm_2:
      then:
        - logger.log: "DS3231 alarm 2 fired"

# Use SNTP to get real time, then push it into the DS3231 on every sync.
time:
  - platform: sntp
    id: sntp_time
    on_time_sync:
      then:
        - ds3231.write_time: ds3231_time
  - platform: ds3231
    ds3231_id: ds3231_hub
    id: ds3231_time
    # Pull time from the RTC into the system clock every minute.
    update_interval: 1min

sensor:
  - platform: ds3231
    ds3231_id: ds3231_hub
    name: DS3231 Temperature
    # celsius (default) or fahrenheit; also sets unit_of_measurement to match.
    unit: celsius
    update_interval: 30s
    web_server:
      sorting_group_id: ds3231_group

text_sensor:
  # The system clock, kept in sync by the ds3231 time platform.
  - platform: template
    name: DS3231 RTC Time
    update_interval: 5s
    web_server:
      sorting_group_id: ds3231_group
    lambda: |-
      auto t = id(ds3231_time).now();
      if (!t.is_valid()) return {"unknown"};
      return t.strftime("%Y-%m-%d %H:%M:%S");
  # The alarm actually programmed into the chip's registers.
  - platform: template
    name: DS3231 Alarm 1 Setting
    update_interval: 10s
    web_server:
      sorting_group_id: ds3231_alarm_group
    lambda: |-
      char buf[40];
      if (!id(ds3231_hub)->describe_alarm_1(buf, sizeof(buf))) return {"not set"};
      return {buf};

binary_sensor:
  - platform: ds3231
    ds3231_id: ds3231_hub
    alarm_1:
      name: DS3231 Alarm 1 Fired
      web_server:
        sorting_group_id: ds3231_alarm_group
    alarm_2:
      name: DS3231 Alarm 2 Fired
      web_server:
        sorting_group_id: ds3231_alarm_group
    oscillator_stopped:
      name: DS3231 Oscillator Stopped
      web_server:
        sorting_group_id: ds3231_group

switch:
  - platform: ds3231
    ds3231_id: ds3231_hub
    enable_32khz_output:
      name: DS3231 32 kHz Output
      web_server:
        sorting_group_id: ds3231_group
    # Arm/disarm an alarm without reprogramming its time.
    alarm_1:
      name: DS3231 Alarm 1 Enabled
      web_server:
        sorting_group_id: ds3231_alarm_group
    alarm_2:
      name: DS3231 Alarm 2 Enabled
      web_server:
        sorting_group_id: ds3231_alarm_group

select:
  - platform: ds3231
    ds3231_id: ds3231_hub
    output_mode:
      name: DS3231 INT/SQW Mode
      web_server:
        sorting_group_id: ds3231_group
    square_wave_frequency:
      name: DS3231 Square Wave Frequency
      web_server:
        sorting_group_id: ds3231_group

  # Alarm builder: match mode (input-only, applied by the buttons below).
  - platform: template
    id: alarm1_mode
    name: Alarm 1 Mode
    optimistic: true
    restore_value: true
    initial_option: Daily at H:M:S
    options:
      - Every second
      - Match seconds
      - Match minutes + seconds
      - Daily at H:M:S
      - Day-of-month at H:M:S
      - Weekday at H:M:S
    web_server:
      sorting_group_id: ds3231_alarm1_builder_group
  # Alarm 2 has no per-second modes.
  - platform: template
    id: alarm2_mode
    name: Alarm 2 Mode
    optimistic: true
    restore_value: true
    initial_option: Daily at H:M
    options:
      - Every minute
      - Match minutes
      - Daily at H:M
      - Day-of-month at H:M
      - Weekday at H:M
    web_server:
      sorting_group_id: ds3231_alarm2_builder_group

number:
  - platform: ds3231
    ds3231_id: ds3231_hub
    aging_offset:
      name: DS3231 Aging Offset
      web_server:
        sorting_group_id: ds3231_group

  # Alarm 1 builder: input-only fields. Day is day-of-month (1-31) or weekday
  # (1-7, 1 = Sunday) depending on the mode; ignored by the other modes.
  - platform: template
    id: alarm1_hour
    name: Alarm 1 Hour
    optimistic: true
    restore_value: true
    initial_value: 7
    min_value: 0
    max_value: 23
    step: 1
    mode: box
    web_server:
      sorting_group_id: ds3231_alarm1_builder_group
  - platform: template
    id: alarm1_minute
    name: Alarm 1 Minute
    optimistic: true
    restore_value: true
    initial_value: 30
    min_value: 0
    max_value: 59
    step: 1
    mode: box
    web_server:
      sorting_group_id: ds3231_alarm1_builder_group
  - platform: template
    id: alarm1_second
    name: Alarm 1 Second
    optimistic: true
    restore_value: true
    initial_value: 0
    min_value: 0
    max_value: 59
    step: 1
    mode: box
    web_server:
      sorting_group_id: ds3231_alarm1_builder_group
  - platform: template
    id: alarm1_day
    name: Alarm 1 Day
    optimistic: true
    restore_value: true
    initial_value: 1
    min_value: 1
    max_value: 31
    step: 1
    mode: box
    web_server:
      sorting_group_id: ds3231_alarm1_builder_group

  # Alarm 2 builder: no seconds field (alarm 2 always matches at :00).
  - platform: template
    id: alarm2_hour
    name: Alarm 2 Hour
    optimistic: true
    restore_value: true
    initial_value: 8
    min_value: 0
    max_value: 23
    step: 1
    mode: box
    web_server:
      sorting_group_id: ds3231_alarm2_builder_group
  - platform: template
    id: alarm2_minute
    name: Alarm 2 Minute
    optimistic: true
    restore_value: true
    initial_value: 0
    min_value: 0
    max_value: 59
    step: 1
    mode: box
    web_server:
      sorting_group_id: ds3231_alarm2_builder_group
  - platform: template
    id: alarm2_day
    name: Alarm 2 Day
    optimistic: true
    restore_value: true
    initial_value: 2
    min_value: 1
    max_value: 31
    step: 1
    mode: box
    web_server:
      sorting_group_id: ds3231_alarm2_builder_group

button:
  - platform: template
    name: DS3231 Sync System Time To RTC
    web_server:
      sorting_group_id: ds3231_group
    on_press:
      - ds3231.write_time: ds3231_time

  - platform: template
    name: DS3231 Read RTC To System Time
    web_server:
      sorting_group_id: ds3231_group
    on_press:
      - ds3231.read_time: ds3231_time

  - platform: template
    name: DS3231 Force Temperature Conversion
    web_server:
      sorting_group_id: ds3231_group
    on_press:
      - ds3231.force_temperature_conversion: ds3231_hub

  # Fixed-value alarms via the declarative ds3231.set_alarm_* actions.
  - platform: template
    name: DS3231 Set Alarm 1 (daily 07:30:00)
    web_server:
      sorting_group_id: ds3231_alarm_group
    on_press:
      - ds3231.set_alarm_1:
          id: ds3231_hub
          mode: MATCH_HOUR_MINUTE_SECOND
          hour: 7
          minute: 30
          second: 0

  - platform: template
    name: DS3231 Set Alarm 2 (08:00 on Mondays)
    web_server:
      sorting_group_id: ds3231_alarm_group
    on_press:
      - ds3231.set_alarm_2:
          id: ds3231_hub
          mode: MATCH_DAY_OF_WEEK
          day_of_week: 2
          hour: 8
          minute: 0

  # Applies the alarm 1 builder inputs (mode select + hour/minute/second/day
  # numbers) to the chip. The "DS3231 Alarm 1 Setting" text sensor shows the result.
  - platform: template
    name: DS3231 Alarm 1 Apply
    web_server:
      sorting_group_id: ds3231_alarm1_builder_group
    on_press:
      - lambda: |-
          using namespace esphome::ds3231;
          DS3231AlarmSpec spec;
          spec.hour = (uint8_t) id(alarm1_hour).state;
          spec.minute = (uint8_t) id(alarm1_minute).state;
          spec.second = (uint8_t) id(alarm1_second).state;
          spec.day = (uint8_t) id(alarm1_day).state;
          auto sel = id(alarm1_mode).current_option();
          DS3231Alarm1Mode mode = DS3231Alarm1Mode::DS3231_ALARM_1_MODE_EVERY_SECOND;
          if (sel == "Match seconds") {
            mode = DS3231Alarm1Mode::DS3231_ALARM_1_MODE_MATCH_SECOND;
          } else if (sel == "Match minutes + seconds") {
            mode = DS3231Alarm1Mode::DS3231_ALARM_1_MODE_MATCH_MINUTE_SECOND;
          } else if (sel == "Daily at H:M:S") {
            mode = DS3231Alarm1Mode::DS3231_ALARM_1_MODE_MATCH_HOUR_MINUTE_SECOND;
          } else if (sel == "Day-of-month at H:M:S") {
            mode = DS3231Alarm1Mode::DS3231_ALARM_1_MODE_MATCH_DAY_OF_MONTH;
          } else if (sel == "Weekday at H:M:S") {
            mode = DS3231Alarm1Mode::DS3231_ALARM_1_MODE_MATCH_DAY_OF_WEEK;
          }
          id(ds3231_hub)->set_alarm_1(mode, spec);

  # Alarm 2 has no seconds - spec.second stays 0 and the chip matches at :00.
  - platform: template
    name: DS3231 Alarm 2 Apply
    web_server:
      sorting_group_id: ds3231_alarm2_builder_group
    on_press:
      - lambda: |-
          using namespace esphome::ds3231;
          DS3231AlarmSpec spec;
          spec.hour = (uint8_t) id(alarm2_hour).state;
          spec.minute = (uint8_t) id(alarm2_minute).state;
          spec.day = (uint8_t) id(alarm2_day).state;
          auto sel = id(alarm2_mode).current_option();
          DS3231Alarm2Mode mode = DS3231Alarm2Mode::DS3231_ALARM_2_MODE_EVERY_MINUTE;
          if (sel == "Match minutes") {
            mode = DS3231Alarm2Mode::DS3231_ALARM_2_MODE_MATCH_MINUTE;
          } else if (sel == "Daily at H:M") {
            mode = DS3231Alarm2Mode::DS3231_ALARM_2_MODE_MATCH_HOUR_MINUTE;
          } else if (sel == "Day-of-month at H:M") {
            mode = DS3231Alarm2Mode::DS3231_ALARM_2_MODE_MATCH_DAY_OF_MONTH;
          } else if (sel == "Weekday at H:M") {
            mode = DS3231Alarm2Mode::DS3231_ALARM_2_MODE_MATCH_DAY_OF_WEEK;
          }
          id(ds3231_hub)->set_alarm_2(mode, spec);
```
