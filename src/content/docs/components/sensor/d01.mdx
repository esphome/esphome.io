The `d01` sensor platform allows you to use YYS D01 particulate matter sensors ([datasheet](https://manuals.plus/ae/1005006417362019))
with ESPHome. This is a similar form factor to the [PM1006](/components/sensor/pm1006) sensor, though not a direct replacement. It reports a range of 5~2500µg/m³ particle concentration, though these are the uncalibrated limits. See the **filter** section below for proper calculation. The effective range is 0~1000µg/m³.

Communication is done using UART, so you need to have an [UART bus](/components/uart) in your configuration with the `rx_pin` connected to the TX pin of the D01.
The baud rate needs to be set to 9600.

```yaml
# Example configuration entry
uart:
  rx_pin: GPIO4 #D2
  baud_rate: 9600

sensor:
  - platform: d01
    pm_2_5:
      name: "D01 PM2.5 Concentration"
      filter:
        - lambda: return (x - 5.0) * 0.4;
    update_interval: 2s
```

## Configuration variables

- **pm_2_5**: Use the concentration of particulates of size less than 2.5µm in µg per cubic meter.
  All options from [Sensor](/components/sensor).

- **filter**: The correction filter applied to the inbound reported PM2.5 value. The hardware reports values 2.5 times higher than the actual concentration of PM2.5, and a K-factor needs to be applied per their documentation. The recommended starting value is 0.4. Additionally, the minimum reportable value is 5µg/m³, so subtraction of 5.0 from the raw value is also needed.

- **uart_id** (*Optional*, [ID](/guides/configuration-types#id)): Manually specify the ID of the [UART Component](/components/uart) if you want
  to use multiple UART buses.

- **update_interval** ([Time](/guides/configuration-types#time)): Update the sensor at the time interval specified. The sensor sends packets every 1.4 seconds, so a window 2 seconds or larger should be sensible. Defaults to never, so some value is required.
