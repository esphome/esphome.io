The `wifi_info` sensor platform exposes WiFi information via numeric sensors,
complementing the [WiFi Info Text Sensor](/components/text_sensor/wifi_info/).

```yaml
# Example configuration entry
sensor:
  - platform: wifi_info
    channel:
      name: Device Connected Channel
```

## Configuration Variables

- **channel** (*Optional*): Expose the channel of the currently connected WiFi network as a sensor.
  The sensor has no state while the device is not connected. All options from
  [Sensor](/components/sensor/#config-sensor).
