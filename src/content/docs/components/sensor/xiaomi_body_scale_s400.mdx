The `xiaomi_body_scale_s400` sensor platform lets you track the output of Xiaomi Body Composition Scale S400 devices using the [ESP32 BLE Tracker](/components/esp32_ble_tracker/). This component listens **passively** to BLE advertisement packets and does not pair with the device, so ESPHome has no impact on battery life.

The scale broadcasts encrypted MiBeacon packets (UUID `0xFE95`). A **bindkey** is required to decrypt the payload. The bindkey can be extracted from the Xiaomi Cloud using [token_extractor](https://github.com/PiotrMachowski/Xiaomi-cloud-tokens-extractor) — use the **BLE KEY** field.

Each measurement cycle produces **two BLE packets**:

- **Packet 1** — weight + heart rate + `impedance_low` only (50 kHz, low frequency, larger value)
- **Packet 2** — `impedance_high` (250 kHz, high frequency, smaller value)

> [!NOTE]
> **Impedance naming convention** follows the BIA standard used by [bodymiscale](https://github.com/dckiller51/bodymiscale):
> `low`/`high` refers to the **measurement frequency**, not the numerical value.
> At 50 kHz, current flows only through extracellular fluid → higher resistance.
> At 250 kHz, current penetrates cell membranes → lower resistance.

## Configuration

### Minimal

```yaml
esp32_ble_tracker:

sensor:
  - platform: xiaomi_body_scale_s400
    mac_address: "XX:XX:XX:XX:XX:XX"
    bindkey: "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
    weight:
      name: "Scale Weight"
    impedance_low:
      name: "Scale Impedance Low"
    impedance_high:
      name: "Scale Impedance High"
    heart_rate:
      name: "Scale Heart Rate"
    profile_id:
      name: "Scale Profile ID"
    stabilized:
      name: "Scale Stabilized"
```

### With auto-reset

Adding a `timeout` filter resets all sensors to `0` after 30 seconds if no new measurement is received.

```yaml
sensor:
  - platform: xiaomi_body_scale_s400
    mac_address: "XX:XX:XX:XX:XX:XX"
    bindkey: "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
    weight:
      name: "Scale Weight"
      filters:
        - timeout:
            timeout: 30s
            value: !lambda return 0;
    impedance_low:
      name: "Scale Impedance Low"
      filters:
        - timeout:
            timeout: 30s
            value: !lambda return 0;
    impedance_high:
      name: "Scale Impedance High"
      filters:
        - timeout:
            timeout: 30s
            value: !lambda return 0;
    heart_rate:
      name: "Scale Heart Rate"
      filters:
        - timeout:
            timeout: 30s
            value: !lambda return 0;
    profile_id:
      name: "Scale Profile ID"
      filters:
        - timeout:
            timeout: 30s
            value: !lambda return 0;
    stabilized:
      name: "Scale Stabilized"
```

## Configuration Variables

- **mac_address** (**Required**, MAC Address): The MAC address of the scale.
- **bindkey** (**Required**, string): 32-character hex key to decrypt the BLE payload.
- **weight** (_Optional_): Stabilized weight in kg.
  - All options from [Sensor](/components/sensor/).
- **impedance_low** (_Optional_): Low-frequency impedance at **50 kHz** in Ω. Numerically larger value (~558 Ω). Published together with weight and heart rate.
  - All options from [Sensor](/components/sensor/).
- **impedance_high** (_Optional_): High-frequency impedance at **250 kHz** in Ω. Numerically smaller value (~503 Ω). Published in the second packet without weight or heart rate.
  - All options from [Sensor](/components/sensor/).
- **impedance** (_Optional_): Alias for `impedance_high` (250 kHz). Provided for single-frequency compatibility.
  - All options from [Sensor](/components/sensor/).
- **heart_rate** (_Optional_): Heart rate in bpm.
  - All options from [Sensor](/components/sensor/).
- **profile_id** (_Optional_): User profile slot (1–5, matches the Xiaomi Home app user assignment).
  - All options from [Sensor](/components/sensor/).
- **stabilized** (_Optional_): Binary sensor that turns `ON` when the measurement
  cycle is complete (last BLE packet received). Turns `OFF` during the measurement.
  - All options from [Binary Sensor](/components/binary_sensor/).

## BLE Payload Structure

The S400 broadcasts encrypted MiBeacon packets of 24 bytes over UUID `0xFE95`:

```text
Byte(s)  Content
0-1      Frame control (0x48 59 = has_data + has_encryption + MiBeacon v5)
2-3      Device type (e.g. 0x3BD5, little-endian)
4        Frame counter (used for deduplication)
5-16     Encrypted payload (12 bytes, AES-CCM, cipher_pos=5)
17-19    Payload counter (used in AES-CCM nonce construction)
20-23    MIC — AES-CCM authentication tag (4 bytes)
```

After decryption, the payload at offset 5 contains object ID `0x6E16` + length `0x09` + 9 data bytes:

```text
data[0]    Profile ID (uint8, 1–5)
data[1-4]  Compressed metrics (uint32, little-endian):
             bits  0-10  Weight × 10     (0.1 kg,  uint11)
             bits 11-17  Heart rate − 50 (1 bpm,   uint7)
             bits 18-31  Impedance × 10  (0.1 Ω,   uint14)
data[5-8]  UNIX timestamp (uint32, requires Xiaomi Home app — not published)
```

Impedance packet routing (BIA frequency convention):

| Packet content           | Frequency | Sensor           | Typical value |
| ------------------------ | --------- | ---------------- | ------------- |
| with weight + heart rate | 50 kHz    | `impedance_low`  | ~558 Ω        |
| without weight           | 250 kHz   | `impedance_high` | ~503 Ω        |

## Getting the Bindkey

1. Install [token_extractor](https://github.com/PiotrMachowski/Xiaomi-cloud-tokens-extractor)
2. Run it and log in with your Xiaomi account
3. Find your scale in the generated list.

> [!NOTE]
> In the Xiaomi Cloud, the S400 variants (`MJTZC01YM` / `MJTZC03YM`) do not appear by their commercial model name. Instead, they are identified as **`yunmai.scales.ms103`**, **`ms104`**, **`ms107`**, or **`xiaomi.scales.ms110`**.

4. Copy the **BLE KEY** field (32 hex characters) — this is your `bindkey`.

## Body Score Calculation

The scale provides raw biometric data (weight + dual-frequency impedance). To compute body composition scores (BMI, body fat %, muscle mass, ECW/ICW, BCM, skeletal muscle mass, etc.) based on weight, impedance, age, height and gender, see:

- [bodymiscale](https://github.com/dckiller51/bodymiscale) — Home Assistant custom component
- [lovelace-body-miscale-card](https://github.com/dckiller51/lovelace-body-miscale-card) — Lovelace card
