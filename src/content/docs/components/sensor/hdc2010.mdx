The HDC2010 Temperature and Humidity sensor allows you to use your HDC2010
([datasheet](https://www.ti.com/lit/ds/symlink/hdc2010.pdf),
[Itbrainpower](https://itbrainpower.net/a-gsm/Arduino-HDC2010-sensor_howto)) sensors with
ESPHome. The [I2C](/i2c/) is
required to be set up in your configuration for this sensor to work.

<Image src={hdc2010FullImg} layout="constrained" alt="" />

<Image src={temperatureHumidityImg} layout="constrained" alt="" />

```yaml
# Example configuration entry
sensor:
  - platform: hdc2010
    temperature:
      name: "Living Room Temperature"
    humidity:
      name: "Living Room Humidity"
    update_interval: 60s
```

## Configuration variables

- **temperature** (**Required**): The information for the temperature sensor.

  - All options from [Sensor](/sensor/).

- **humidity** (**Required**): The information for the humidity sensor

  - All options from [Sensor](/sensor/).

- **update_interval** (*Optional*, [Time](/time/)): The interval to check the sensor. Defaults to `60s`.
