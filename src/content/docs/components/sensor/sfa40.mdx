The `sfa40` sensor platform allows you to use your Sensirion SFA40 formaldehyde
([datasheet](https://sensirion.com/media/documents/5B06EDD9/69F84BD8/Sensirion_Datasheet_SFA40.pdf)) sensor
with ESPHome. The sensor also reports temperature and relative humidity. The [I²C Bus](/components/i2c/) is required
to be set up in your configuration for this sensor to work.

<Image src="/images/sfa40.jpg" width={300} height={169} layout="constrained" alt="SFA40 formaldehyde sensor" />

```yaml
# Example configuration entry
sensor:
  - platform: sfa40
    wait_for_ready: true
    formaldehyde:
      name: "Formaldehyde"
    temperature:
      name: "Temperature"
    humidity:
      name: "Humidity"
```

## Configuration Variables

- **formaldehyde** (*Optional*): The information for the formaldehyde concentration sensor.
  All options from [Sensor](/components/sensor/).

- **temperature** (*Optional*): The information for the temperature sensor.
  All options from [Sensor](/components/sensor/).

- **humidity** (*Optional*): The information for the relative humidity sensor.
  All options from [Sensor](/components/sensor/).

- **address** (*Optional*, int): Manually specify the I²C address of the sensor.
  Defaults to `0x5D`.

- **wait_for_ready** (*Optional*, boolean): If enabled, the device waits for the sensor to be ready
  before reading measurements. Defaults to `true`.

- **update_interval** (*Optional*, [Time](/guides/configuration-types/#time)): The interval to check the sensor.
  Defaults to `60s`.
