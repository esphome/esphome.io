The `bq76972` platform allows you to use a BQ76972 high accuracy battery monitor
([datasheet](https://www.ti.com/lit/ds/slusfc9/slusfc9.pdf),
[Technical Reference Manual](https://www.ti.com/lit/ug/sluucw9/sluucw9.pdf))
in ESPHome. It uses the [I²C Bus](/components/i2c) for communication. The default I²C address is `0x08`.

The BQ76972 is a 3-series to 16-series cell battery monitor that provides cell voltage readings, 
pack current measurements, coulomb counting, and flexible thermistor monitoring options across multiple pins.

## Configuration Variables

- **address** (*Optional*, int): The I²C address of the device. Defaults to `0x08`.
- **id** (**Required**, [ID](/guides/configuration-types/#id)): Manually specify an ID for this component instance to be referenced by child sensors.
- **update_interval** (*Optional*, [Time](/guides/configuration-types#time)): How often to poll the sensor. Defaults to `10s`.
- **address** (*Optional*, int): The initial I²C address of the device. Defaults to `0x08`.
- **crc_enabled** (*Optional*, boolean): Whether to enable CRC validation for communication. Defaults to `false`.
- **reg_disabled** (*Optional*, boolean): Sets REG0 disabling option in configuration. Defaults to `true`.

## Temperature Sensor Variables

All temperature entries are placed under the `sensor` platform pointing to your `bq76972_id`. Each entry is optional.

- **bq76972_id** (**Required**, [ID](/guides/configuration-types/#id)): The ID of the parent `bq76972` component.
- **internal_temperature** (*Optional*): Internal die temperature in °C.
- **cfetoff_temperature** (*Optional*): Temperature recorded by thermistor connected to the CFETOFF pin in °C.
- **dfetoff_temperature** (*Optional*): Temperature recorded by thermistor connected to the DFETOFF pin in °C.
- **alert_temperature** (*Optional*): Temperature recorded by thermistor connected to the ALERT pin in °C.
- **ts1_temperature** (*Optional*): Temperature recorded by thermistor connected to the TS1 pin in °C.
- **ts2_temperature** (*Optional*): Temperature recorded by thermistor connected to the TS2 pin in °C.
- **ts3_temperature** (*Optional*): Temperature recorded by thermistor connected to the TS3 pin in °C.
- **hdq_temperature** (*Optional*): Temperature recorded by thermistor connected to the HDQ pin in °C.
- **dchg_temperature** (*Optional*): Temperature recorded by thermistor connected to the DCHG pin in °C.
- **ddsg_temperature** (*Optional*): Temperature recorded by thermistor connected to the DDSG pin in °C.

## Number Entity Variables (I²C Address Reprogramming)

Allows updating the internal Data Memory of the BQ76972 to switch its hardware I²C address.

- **bq76972_id** (**Required**, [ID](/guides/configuration-types/#id)): The ID of the parent `bq76972` component.
- **i2c_address_setter** (**Required**): Configures a numeric text box in Home Assistant. Pre-populates with the device's currently active address.
  - All standard options from [Number](/components/number).
