The `HM3301` sensor platform allows you to use your HM3301 particulate matter sensor
([more info](http://wiki.seeedstudio.com/Grove-Laser_PM2.5_Sensor-HM3301))
sensors with ESPHome.

The sensor communicate with board by [I²C](/components/i2c) protocol, and requires 3.3v.

```yaml
# Example configuration entry
i2c:

sensor:
  - platform: hm3301
    pm_1_0:
      name: "PM1.0"
    pm_2_5:
      name: "PM2.5"
    pm_10_0:
      name: "PM10.0"
```

## Configuration variables

- **pm_1_0** (*Optional*): Use the concentration of particulates of size less than 1.0µm in µg per cubic meter.

  - All options from [Sensor](/components/sensor).

- **pm_2_5** (*Optional*): Use the concentration of particulates of size less than 2.5µm in µg per cubic meter.

  - All options from [Sensor](/components/sensor).

- **pm_10_0** (*Optional*): Use the concentration of particulates of size less than 10.0µm in µg per cubic meter.

  - All options from [Sensor](/components/sensor).

## Air Quality Index

To get an air quality index (US EPA AQI or European CAQI) from the HM3301's PM2.5 and PM10 readings, use the
[AQI sensor](/components/sensor/aqi/). The built-in `aqi:` option was removed in ESPHome 2026.12.0.

```yaml
sensor:
  - platform: hm3301
    pm_2_5:
      id: pm_2_5
      name: "PM2.5"
    pm_10_0:
      id: pm_10_0
      name: "PM10.0"
  - platform: aqi
    name: "Air Quality Index"
    pm_2_5: pm_2_5
    pm_10_0: pm_10_0
    calculation_type: "CAQI"  # or "AQI" for US EPA standard
```
