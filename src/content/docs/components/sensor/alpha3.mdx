The `alpha3` component monitors and controls a supported Grundfos ALPHA3 Model B circulator pump over BLE.
It requires an ESP32 and a configured [BLE Client](/components/ble_client/).

The component discovers the pump's protocol address after connecting. It validates responses before publishing values and
uses the pump's confirmed read-back value after a control command.

## Configuration Entry

```yaml
sensor:
  - platform: alpha3
    ble_client_id: alpha3_ble
```

## Configuration Variables

### Sensor Platform

- **id** (*Optional*, [ID](/guides/configuration-types/#id)): The ID of the ALPHA3 component. Required when using
  the diagnostic or control platforms below.
- **ble_client_id** (**Required**, [ID](/guides/configuration-types/#id)): The BLE client connected to the pump.
- **update_interval** (*Optional*, [Time](/guides/configuration-types/#time)): Polling interval. Defaults to `15s`.
- **flow** (*Optional*, [Sensor](/components/sensor/)): Estimated volume flow in `m³/h`.
- **head** (*Optional*, [Sensor](/components/sensor/)): Estimated pump head in `m`.
- **power** (*Optional*, [Sensor](/components/sensor/)): Electrical power in `W`.
- **current** (*Optional*, [Sensor](/components/sensor/)): Electrical current in `A`.
- **speed** (*Optional*, [Sensor](/components/sensor/)): Rotor speed in `RPM`.
- **voltage** (*Optional*, [Sensor](/components/sensor/)): Supply voltage in `V`.
- **operating_hours** (*Optional*, [Sensor](/components/sensor/)): Cumulative operating time in hours.
- **energy** (*Optional*, [Sensor](/components/sensor/)): Cumulative electrical energy in `kWh`.
- **starts** (*Optional*, [Sensor](/components/sensor/)): Cumulative pump start count.
- **alarm_code** (*Optional*, [Sensor](/components/sensor/)): Active alarm code.
- **warning_code** (*Optional*, [Sensor](/components/sensor/)): Active warning code.

### Diagnostic Entities

Use the `alpha3` platforms below to expose connection and operating-state diagnostics:

```yaml
binary_sensor:
  - platform: alpha3
    alpha3_id: alpha3_pump
    ready:
      name: "ALPHA3 Ready"

text_sensor:
  - platform: alpha3
    alpha3_id: alpha3_pump
    realized_operation:
      name: "ALPHA3 Realized Operation"
    active_control_source:
      name: "ALPHA3 Active Control Source"
```

- **alpha3_id** (**Required**, [ID](/guides/configuration-types/#id)): The ID of the ALPHA3 component.
- **ready** (*Optional*, [Binary Sensor](/components/binary_sensor/)): `true` after address discovery and exact
  writable pump identity validation complete. Use it to guard control automations.
- **realized_operation** (*Optional*, [Text Sensor](/components/text_sensor/)): The operation currently realized by
  the pump.
- **active_control_source** (*Optional*, [Text Sensor](/components/text_sensor/)): The source currently controlling
  the pump.

## Controls

The component exposes mode selects and setpoint numbers through the standard [Select](/components/select/) and
[Number](/components/number/) platforms:

```yaml
select:
  - platform: alpha3
    alpha3_id: alpha3_pump
    operating_mode:
      name: "ALPHA3 Operating Mode"
    control_mode:
      name: "ALPHA3 Control Mode"

number:
  - platform: alpha3
    alpha3_id: alpha3_pump
    constant_speed_setpoint:
      name: "ALPHA3 Constant Speed Setpoint"
    constant_pressure_setpoint:
      name: "ALPHA3 Constant Pressure Setpoint"
    proportional_pressure_setpoint:
      name: "ALPHA3 Proportional Pressure Setpoint"
```

- **alpha3_id** (**Required**, [ID](/guides/configuration-types/#id)): The ID of the ALPHA3 component.
- **operating_mode** (*Optional*, [Select](/components/select/)): `Normal`, `Stop`, `Min`, or `Max`.
- **control_mode** (*Optional*, [Select](/components/select/)): `Constant pressure`, `Proportional pressure`,
  `Constant speed`, `AUTOADAPT radiator`, `AUTOADAPT underfloor`, or `AUTOADAPT radiator and underfloor`.
- **constant_speed_setpoint** (*Optional*, [Number](/components/number/)): Constant-speed setpoint in `RPM`. The
  displayed range is 0–10000 RPM.
- **constant_pressure_setpoint** (*Optional*, [Number](/components/number/)): Constant-pressure setpoint in `m`. The
  displayed range is 0–20 m.
- **proportional_pressure_setpoint** (*Optional*, [Number](/components/number/)): Proportional-pressure setpoint in
  `m`. The displayed range is 0–20 m.

Controls are available only when the connected pump has the exact supported identity and required capability.
ESPHome learns the pump's factory setpoint limits, preserves unrelated configuration values when writing, and publishes a
control value only after the pump confirms it. A setpoint outside the factory limits is rejected even if it is inside the
number entity's displayed range.

> [!CAUTION]
> Changing a mode or setpoint can affect heating-system performance. Confirm that a setting is safe for the installation
> before applying it.

## Letting Another BLE Application Connect

A pump can have only one active BLE connection. To use another BLE application, configure the BLE client with
`auto_connect: false` and expose buttons that explicitly connect and disconnect ESPHome:

```yaml
ble_client:
  - mac_address: XX:XX:XX:XX:XX:XX
    id: alpha3_ble
    auto_connect: false

button:
  - platform: template
    name: "ALPHA3 Connect"
    on_press:
      - ble_client.connect: alpha3_ble

  - platform: template
    name: "ALPHA3 Disconnect"
    on_press:
      - ble_client.disconnect: alpha3_ble
```

Press **ALPHA3 Connect** when ESPHome should monitor or control the pump. Before using another BLE application,
press **ALPHA3 Disconnect** and wait until `ALPHA3 Ready` is `false`. With `auto_connect: false`, ESPHome does not
reconnect until the connect button is pressed again.

## Notes

> [!WARNING]
> Older pumps such as the ALPHA2 and ALPHA3 Model A are not compatible because they do not have integrated Bluetooth.
> The ALPHA Reader uses a different protocol and is not compatible with this component.

> [!NOTE]
> The ESP32 must be paired with the pump before it can read or control it. For initial pairing, press the pump's
> connectivity button. After pairing, the BLE client can connect to the pump.
