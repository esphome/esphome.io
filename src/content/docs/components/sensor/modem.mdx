Retrieve Signal Strength (RSSI) and Bit Error Rate (BER) from the [Modem](/components/modem)

```yaml
modem:
  id: atmodem


sensor:
- platform: modem_info
  rssi:
    name: rssi
  ber:
    name: ber
```

## Configuration variables

- **rssi** (*Optional*, [number](/components/sensor#config-sensor)): Received Signal Strength Indicator (RSSI) in dB. The range is from -113 dB (weakest) to -51 dB (strongest). All options from [Sensor](/components/sensor#config-sensor).
- **ber** (*Optional*, [number](/components/sensor#config-sensor)): Bit Error Rate (BER) in percent (%). This may not be available on all modem models. All options from [Sensor](/components/sensor#config-sensor).
- **update_interval** (*Optional*, [Time](/guides/configuration-types#time)): The interval to poll the modem for new values. Defaults to `60s`.
- All other options from [Sensor](/components/sensor#config-sensor).
