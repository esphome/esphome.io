### Round to Significant Digits Filter


Rounds the value to the specified number of significant digits. Takes an integer from 1 to 6.

```yaml
# Example configuration entry
filters:
  - round_to_significant_digits: 2
    # 3.14159 -> 3.1
    # 157079 -> 160000

# Example configuration entry
filters:
  - round_to_significant_digits: 4
    # 3.14159 -> 3.142
    # 157079 -> 157100
```
