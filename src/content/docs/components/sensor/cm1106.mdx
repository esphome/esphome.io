Communication with the CM1106 sensor is done via UART, so you need to define a
[UART bus](/components/uart) in your configuration. Connect the `rx_pin` to the TX pin of the CM1106
and the `tx_pin` to the RX pin of the CM1106 (note that the TX/RX labels are from the sensor’s
perspective). Additionally, set the baud rate to 9600 for proper communication.

```yaml
# Example configuration entry
sensor:
  - platform: cm1106
    co2:
      name: CM1106 CO2 Value
```

## Configuration variables

- **co2** (*Optional*): The CO2 data from the sensor in parts per million (ppm).
  All options from [Sensor](/components/sensor).

- **update_interval** (*Optional*, [Time](/guides/configuration-types#time)): The interval to check the
  sensor. Defaults to `60s`.

- **uart_id** (*Optional*, [ID](/guides/configuration-types#id)): Manually specify the ID of the [UART Component](/components/uart) if you want
  to use multiple UART buses.

- **id** (*Optional*, [ID](/guides/configuration-types#id)): Manually specify the ID used for actions.

- **automatic_baseline_calibration** (*Optional*, boolean or mapping): CM1106 has an automatic
  baseline calibration procedure (ABC). The sensor refreshes the baseline against the lowest
  reading observed during each calibration cycle; with the default settings a cycle starts 24 hours
  after the sensor is powered on and then repeats every 15 days.
  Set this value to `false` to disable ABC on boot (recommended for most indoor sensors).
  Set this value to `true` to enable ABC on boot.
  No calibration command is sent if not set (the sensor's stored logic is used).

  - **cycle** (*Optional*, int, [1, 90]): Calibration
    cycle interval in days. Defaults to `15`.
  - **baseline** (*Optional*, int, [400, 10000]): The
    reference concentration the baseline is refreshed against, in ppm. Defaults to `400`. ABC
    requires at least 400ppm; the value cannot be set below the factory reference.

  Set to `true` to enable ABC on boot with the default cycle and baseline:

  ```yaml
  automatic_baseline_calibration: true
  ```

  Alternatively, provide a mapping to customize the cycle and baseline; the mapping implicitly
  enables ABC:

  ```yaml
  automatic_baseline_calibration:
    cycle: 7
    baseline: 420
  ```

## `cm1106.calibrate_zero` Action

This [action](/automations/actions#all-actions) executes zero point calibration command on the sensor with the given ID.

To perform zero-point calibration, the CM1106 sensor must operate in a stable 400ppm CO₂ environment for
at least 20 minutes before executing this function.

```yaml
on_...:
  then:
    - cm1106.calibrate_zero: my_cm1106_id
```

You can provide an [action](/components/api#api-device-actions) to perform from Home Assistant

```yaml
api:
  actions:
    - action: cm1106_calibrate_zero
      then:
        - cm1106.calibrate_zero: my_cm1106_id
```

Examples:

Button to start the calibration process:

```yaml
button:
  - platform: template
    name: "CM1106 Calibration"
    entity_category: diagnostic
    on_press:
      then:
        - cm1106.calibrate_zero: my_cm1106_id
```

Pseudo-automatic calibration by CO2 value:

```yaml
binary_sensor:
  - platform: template
    id: co2_calibration
    lambda: |-
      if (id(co2sensor).get_state() < 400) {
        return true;
      } else {
        return false;
      }
    filters:
      - delayed_on: 15min
    on_press:
      then:
        - cm1106.calibrate_zero: my_cm1106_id
    internal: true
```

## `cm1106.abc_enable` Action

This [action](/automations/actions#all-actions) enables automatic baseline calibration on the sensor with the given ID.

```yaml
on_...:
  then:
    - cm1106.abc_enable: my_cm1106_id
```

## `cm1106.abc_disable` Action

This [action](/automations/actions#all-actions) disables automatic baseline calibration on the sensor with the given ID.

```yaml
on_...:
  then:
    - cm1106.abc_disable: my_cm1106_id
```

You can provide a switch to control ABC from Home Assistant.

```yaml
switch:
  - platform: template
    name: "CM1106 ABC"
    optimistic: true
    on_turn_on:
      cm1106.abc_enable: my_cm1106_id
    on_turn_off:
      cm1106.abc_disable: my_cm1106_id
```
