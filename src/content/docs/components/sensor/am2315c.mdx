The `am2315c` Temperature+Humidity sensor allows you to use your AM2315C
([datasheet](https://cdn-shop.adafruit.com/product-files/5182/5182_AM2315C.pdf)) I²C-based sensor with ESPHome.

&lt;Img src="am2315c-full.jpg" alt="Image" caption="AM2315C Temperature & Humidity Sensor." class="align-center" width="50.0%" /&gt;

<Img src="temperature-humidity.png" alt="Image" class="align-center" width="80.0%" />

```yaml
# Example configuration entry
sensor:
  - platform: am2315c
    temperature:
      name: "Living Room Temperature"
    humidity:
      name: "Living Room Humidity"
```

## Configuration variables

- **temperature** (*Optional*): The temperature sensor.
  All options from [Sensor](/components/sensor).

- **humidity** (*Optional*): The humidity sensor.
  All options from [Sensor](/components/sensor).

- **update_interval** (*Optional*, [Time](/guides/configuration-types#time)): The interval to check the sensor. Defaults to `60s`.
