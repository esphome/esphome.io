The `ips7100` sensor platform allows you to use your Piera Systems IPS-7100
Intelligent Particle Sensor
([datasheet](https://pierasystems.com/wp-content/uploads/2024/02/IPS-Datasheet-V1.3.8.pdf),
[Piera Systems](https://pierasystems.com/product/piera-7100-intelligent-particle-sensor/)) with ESPHome.

The IPS-7100 is a highly accurate optical particle sensor that uses laser scattering to measure
both mass concentration (µg/m³) and particle count (#/cm³) across 7 size bins: 0.1, 0.3, 0.5, 1.0, 2.5, 5.0, and 10.0 µm.

The [I²C Bus](/components/i2c) is required to be set up in your configuration for this sensor to work.

```yaml
# Example configuration entry
sensor:
  - platform: ips7100
    pm_1_0:
      name: "PM 1.0"
    pm_2_5:
      name: "PM 2.5"
    pm_10_0:
      name: "PM 10.0"
    pmc_0_5:
      name: "PMC 0.5µm"
    pmc_2_5:
      name: "PMC 2.5µm"
```

## Wiring

Connect the sensor to your ESP as follows:

| IPS-7100 Pin | ESP Pin |
|--------------|---------|
| VDD          | 5V      |
| GND          | GND     |
| SDA          | SDA     |
| SCL          | SCL     |
| SEL          | GND     |

> [!NOTE]
> The SEL pin must be connected to GND to enable I²C mode.

## Configuration variables

### PM Mass Concentration Sensors

- **pm_0_1** (*Optional*): Mass concentration of particles ≤0.1 µm (µg/m³).
  All options from [Sensor](/components/sensor).

- **pm_0_3** (*Optional*): Mass concentration of particles ≤0.3 µm (µg/m³).
  All options from [Sensor](/components/sensor).

- **pm_0_5** (*Optional*): Mass concentration of particles ≤0.5 µm (µg/m³).
  All options from [Sensor](/components/sensor).

- **pm_1_0** (*Optional*): Mass concentration of particles ≤1.0 µm (µg/m³).
  All options from [Sensor](/components/sensor).

- **pm_2_5** (*Optional*): Mass concentration of particles ≤2.5 µm (µg/m³).
  All options from [Sensor](/components/sensor).

- **pm_5_0** (*Optional*): Mass concentration of particles ≤5.0 µm (µg/m³).
  All options from [Sensor](/components/sensor).

- **pm_10_0** (*Optional*): Mass concentration of particles ≤10.0 µm (µg/m³).
  All options from [Sensor](/components/sensor).

### Particle Count Sensors

- **pmc_0_1** (*Optional*): Particle count for size ≥0.1 µm (#/cm³).
  All options from [Sensor](/components/sensor).

- **pmc_0_3** (*Optional*): Particle count for size ≥0.3 µm (#/cm³).
  All options from [Sensor](/components/sensor).

- **pmc_0_5** (*Optional*): Particle count for size ≥0.5 µm (#/cm³).
  All options from [Sensor](/components/sensor).

- **pmc_1_0** (*Optional*): Particle count for size ≥1.0 µm (#/cm³).
  All options from [Sensor](/components/sensor).

- **pmc_2_5** (*Optional*): Particle count for size ≥2.5 µm (#/cm³).
  All options from [Sensor](/components/sensor).

- **pmc_5_0** (*Optional*): Particle count for size ≥5.0 µm (#/cm³).
  All options from [Sensor](/components/sensor).

- **pmc_10_0** (*Optional*): Particle count for size ≥10.0 µm (#/cm³).
  All options from [Sensor](/components/sensor).

### Other Configuration

- **address** (*Optional*, int): Manually specify the I²C address of the sensor.
  Defaults to `0x4B`.

- **update_interval** (*Optional*, [Time](/guides/configuration-types#time)): The interval to check the
  sensor. Defaults to `60s`.

## Full Configuration Example

```yaml
sensor:
  - platform: ips7100
    address: 0x4B
    update_interval: 60s
    # PM Mass Concentration (µg/m³)
    pm_0_1:
      name: "PM 0.1"
    pm_0_3:
      name: "PM 0.3"
    pm_0_5:
      name: "PM 0.5"
    pm_1_0:
      name: "PM 1.0"
    pm_2_5:
      name: "PM 2.5"
    pm_5_0:
      name: "PM 5.0"
    pm_10_0:
      name: "PM 10.0"
    # Particle Count (#/cm³)
    pmc_0_1:
      name: "Particle Count 0.1µm"
    pmc_0_3:
      name: "Particle Count 0.3µm"
    pmc_0_5:
      name: "Particle Count 0.5µm"
    pmc_1_0:
      name: "Particle Count 1.0µm"
    pmc_2_5:
      name: "Particle Count 2.5µm"
    pmc_5_0:
      name: "Particle Count 5.0µm"
    pmc_10_0:
      name: "Particle Count 10.0µm"
```
