The `ds3231` number platform exposes the aging offset (trim) register of the
[DS3231 real-time clock](/components/ds3231/). This signed value fine-tunes the oscillator frequency; each
step is roughly 0.1 ppm. Positive values slow the clock down, negative values speed it up. A new value takes
effect on the next temperature conversion.

Set up the [`ds3231`](/components/ds3231/) hub (and the [I²C](/components/i2c/) bus it needs) first.

```yaml
# Example configuration entry
ds3231:
  id: ds3231_hub

number:
  - platform: ds3231
    aging_offset:
      name: "RTC Aging Offset"
```

## Configuration Variables

- **ds3231_id** (*Optional*, [ID](/guides/configuration-types#id)): The ID of the [`ds3231`](/components/ds3231/)
  hub to use when more than one is configured.
- **aging_offset** (**Required**): The aging offset number entity.
  - **min_value** (*Optional*, int): Minimum value. Defaults to `-128`.
  - **max_value** (*Optional*, int): Maximum value. Defaults to `127`.
  - **step** (*Optional*, int): Step size. Defaults to `1`.
  - Config entity category by default. All options from [Number](/components/number/#config-number).
