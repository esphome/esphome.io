The `geolocation` hub component reads position, speed and time from a location source, today a GNSS receiver (GPS,
Galileo, GLONASS, BeiDou and others). Each source is set up as a `geolocation` platform for the protocol it speaks,
and its values are read with `geolocation` sensors and the
[geolocation time source](/components/time/geolocation/).

```yaml
# Example configuration entry
geolocation:
  - platform: nmea
    id: gnss_receiver

sensor:
  - platform: geolocation
    type: latitude
    name: "Latitude"
  - platform: geolocation
    type: longitude
    name: "Longitude"
  - platform: geolocation
    type: altitude
    name: "Altitude"

time:
  - platform: geolocation
```

## Platforms

- [NMEA](/components/geolocation/nmea/): any GNSS receiver that sends standard NMEA 0183 sentences.

## Configuration Variables

### Base Configuration

These options are shared by all `geolocation` platforms.

- **id** (*Optional*, [ID](/guides/configuration-types/#id)): The ID of this receiver, used by the sensors and
  the time source when there is more than one receiver.
- **update_interval** (*Optional*, [Time](/guides/configuration-types/#time)): How often the sensors publish the
  latest values. Defaults to `20s`.
- **field_age** (*Optional*, boolean): Compile in `get_age()` for [lambdas](#using-geolocation-data-in-lambdas),
  which costs 4 bytes of RAM per field. Defaults to `false`.
- **millisecond** (*Optional*, boolean): Compile in the `millisecond` of the time for lambdas. Defaults to `false`.
- **geoid_separation** (*Optional*, boolean): Compile in the geoid separation for lambdas. Defaults to `false`.

Components that need one of these turn it on themselves.

## Sensor

```yaml
# Example configuration entry
sensor:
  - platform: geolocation
    type: speed
    name: "Speed"
```

### Configuration Variables

- **type** (**Required**): The value to report. One of:

  - `latitude`: Latitude in degrees.
  - `longitude`: Longitude in degrees.
  - `altitude`: Altitude above mean sea level in meters.
  - `speed`: Speed over ground in km/h.
  - `course`: Course over ground in degrees from true north.
  - `satellites`: Number of satellites used in the solution.
  - `hdop`: Horizontal dilution of precision.

- **geolocation_id** (*Optional*, [ID](/guides/configuration-types/#id)): The receiver to read from. Only needed when
  there is more than one.
- All other options from [Sensor](/components/sensor/).

A sensor has no value (`NaN`) until the receiver has sent it. Each platform describes when values are kept or
cleared after the fix is lost.

## Using Geolocation Data in Lambdas

`id(gnss_receiver).get_data()` returns the latest values of a receiver. Position and the other measurements are
stored as integers scaled by a power of ten, which keeps the full precision of the receiver; the methods in the table
convert them to `float` values.

```yaml
interval:
  - interval: 10s
    then:
      - lambda: |-
          const auto &data = id(gnss_receiver).get_data();
          if (data.has(geolocation::GEOLOCATION_FIELD_LOCATION)) {
            ESP_LOGI("main", "Position: %.7f, %.7f", data.latitude_e7 * 1e-7, data.longitude_e7 * 1e-7);
          }
```

| Field                                            | Method                                             | Value                                       |
| ------------------------------------------------ | -------------------------------------------------- | ------------------------------------------- |
| `latitude_e7`, `longitude_e7`                    | `latitude()`, `longitude()`                        | Degrees times 10^7, north and east positive |
| `altitude_e3`                                    | `altitude()`                                       | Meters above mean sea level times 1000      |
| `speed_e3`                                       | `speed_knots()`, `speed_kmh()`                     | Knots times 1000                            |
| `course_e2`                                      | `course()`                                         | Degrees from true north times 100           |
| `hdop_e2`                                        | `hdop()`                                           | HDOP times 100                              |
| `horizontal_accuracy_e3`, `vertical_accuracy_e3` | `horizontal_accuracy()`, `vertical_accuracy()`     | Estimated accuracy in meters times 1000     |
| `satellites`                                     |                                                    | Satellites used in the solution             |
| `year`, `month`, `day`                           |                                                    | UTC date                                    |
| `hour`, `minute`, `second`                       |                                                    | UTC time                                    |
| `millisecond`                                    |                                                    | Milliseconds of the UTC time                |
| `geoid_separation_e3`                            | `geoid_separation()`                               | Ellipsoid to sea level, meters times 1000   |

`data.has(field)` is true while the receiver has a value for that field, and `data.is_updated(field)` is true when
the last message set it. The fields are `LOCATION`, `SPEED`, `COURSE`, `ALTITUDE`, `SATELLITES`, `HDOP`, `TIME`,
`DATE`, `HORIZONTAL_ACCURACY`, `VERTICAL_ACCURACY` and `GEOID_SEPARATION`, each with the
`geolocation::GEOLOCATION_FIELD_` prefix, for example `geolocation::GEOLOCATION_FIELD_LOCATION`. Not every platform
sends every field, and `millisecond` and the geoid separation are there only with `millisecond: true` and
`geoid_separation: true`.

With `field_age: true`, `id(gnss_receiver).get_age(field)` gives the milliseconds since a message last set the
field, or `UINT32_MAX` if none has.

## Moving From `gps`

The `gps` component is deprecated and will be removed in 2027.6.0. It becomes a `geolocation` receiver with
`platform: nmea`, each of its sensors becomes a `geolocation` sensor with a `type`, and the time source becomes
`platform: geolocation`. The values do not change, and `field_age`, `millisecond` and `geoid_separation` move to
the receiver.

```yaml
# Before
gps:
  latitude:
    name: "Latitude"
  longitude:
    name: "Longitude"

time:
  - platform: gps
```

```yaml
# After
geolocation:
  - platform: nmea

sensor:
  - platform: geolocation
    type: latitude
    name: "Latitude"
  - platform: geolocation
    type: longitude
    name: "Longitude"

time:
  - platform: geolocation
```

### Lambdas

`get_tiny_gps()` is gone with the TinyGPS++ library; `get_data()` of the `geolocation` receiver gives the same
values. A lambda that already uses `get_data()` or `get_age()` of `gps` only needs the receiver's ID and
`geolocation::GEOLOCATION_FIELD_*` in place of `gps::GPS_FIELD_*`.

| `gps` lambda                                      | `geolocation` lambda                                         |
| ------------------------------------------------- | ------------------------------------------------------------ |
| `get_tiny_gps().location.lat()`                   | `get_data().latitude()`, or `latitude_e7` for full precision |
| `get_tiny_gps().location.lng()`                   | `get_data().longitude()`, or `longitude_e7`                  |
| `get_tiny_gps().altitude.meters()`                | `get_data().altitude()`                                      |
| `get_tiny_gps().speed.kmph()`                     | `get_data().speed_kmh()`                                     |
| `get_tiny_gps().course.deg()`                     | `get_data().course()`                                        |
| `get_tiny_gps().satellites.value()`               | `get_data().satellites`                                      |
| `get_tiny_gps().hdop.hdop()`                      | `get_data().hdop()`                                          |
| `get_tiny_gps().date.year()`, `.time.hour()`, ... | `get_data().year`, `.hour`, ...                              |
| `get_tiny_gps().location.isValid()`               | `get_data().has(geolocation::GEOLOCATION_FIELD_LOCATION)`                  |
