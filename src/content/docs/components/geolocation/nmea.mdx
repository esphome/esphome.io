The `nmea` [geolocation](/components/geolocation/) platform reads GNSS receivers that send the standard NMEA 0183
sentences, which almost every GNSS module does by default.

The platform reads the GGA and RMC sentences from any talker (`GP`, `GN`, `GA`, `GB`, ...). Position, altitude,
speed, course and time are taken only from sentences with a fix, so until the first fix those sensors have no value
(`NaN`). When the fix is lost, they keep the values of the last fix. The satellite count and HDOP are reported with
or without a fix.

A [UART bus](/components/uart/) is required in your configuration; only the RX pin is needed.

```yaml
# Example configuration entry
uart:
  rx_pin: GPIOXX
  baud_rate: 9600

geolocation:
  - platform: nmea

sensor:
  - platform: geolocation
    type: latitude
    name: "Latitude"
  - platform: geolocation
    type: longitude
    name: "Longitude"
```

## Configuration Variables

- **uart_id** (*Optional*, [ID](/guides/configuration-types/#id)): The UART bus of the receiver. Only needed when
  there is more than one.
- All options from the [geolocation base configuration](/components/geolocation/#base-configuration).
