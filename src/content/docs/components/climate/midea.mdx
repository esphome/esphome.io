The `midea` component creates a Midea air conditioner climate device.

> [!NOTE]
> This protocol also used by some vendors:
>
> - [Electrolux](https://www.electrolux.com/en/)
> - [Qlima](https://www.qlima.com/)
> - [Artel](https://www.artelgroup.com/)
> - [Carrier](https://www.carrier.com/)
> - [Comfee](https://www.feelcomfee.com/global/)
> - [Inventor](https://www.inventorairconditioner.com/)
> - [Senville](https://senville.com/)
> - [Cooper & Hunter](https://cooperandhunter.com/)
> - and maybe others
>
> Control is possible with a custom dongle. Example of hardware implementation is [IoT Uni Dongle](https://github.com/dudanov/iot-uni-dongle) or [Midea SLWF-01pro](https://smartlight.me/smart-home-devices/wifi-devices/wifi-dongle-air-conditioners-midea-idea-electrolux-for-home-assistant) ([CloudFree](https://cloudfree.shop/product/ductless-hvac-wi-fi-module/), [Tindie](https://www.tindie.com/products/smartlightme/wifi-dongle-for-air-conditioners-midea-electrolux)).

The Midea air conditioner requires the UART to be configured with `baud_rate: 9600`. The hardware requires **5V logic levels** and does not appear to work with 3.3V logic levels. Use a logic level shifter if building your own dongle.

> [!CAUTION]
> On some models, the indoor unit's internal USB port shares its 5V rail with the unit's display board. WiFi transmit
> current spikes can sag the rail enough to cause display flicker or dropout.
>
> If you power the module from this port, add a 470-1000µF, 16V (or higher) electrolytic capacitor across 5V/GND at the
> module's power input, placed as close to the module as possible. Observe polarity: the positive lead goes to 5V and
> the striped (negative) lead goes to GND. A reversed electrolytic can fail violently.

```yaml
# Example configuration entry
# Main settings
climate:
  - platform: midea
    name: Midea Climate         # Use a unique name.
    period: 1s                  # Optional
    timeout: 2s                 # Optional
    num_attempts: 3             # Optional
    autoconf: true              # Autoconfigure most options.
    beeper: true                # Beep on commands.
    visual:                     # Optional. Example of visual settings override.
      min_temperature: 17 °C    # min: 17
      max_temperature: 30 °C    # max: 30
      temperature_step: 0.5 °C  # min: 0.5
    supported_modes:            # Optional. All capabilities in this section may be detected by autoconf.
      - FAN_ONLY
      - HEAT_COOL
      - COOL
      - HEAT
      - DRY
    custom_fan_modes:           # Optional
      - SILENT
      - TURBO
    supported_presets:          # Optional. All capabilities in this section may be detected by autoconf.
      - ECO
      - BOOST
      - SLEEP
    custom_presets:             # Optional. All capabilities in this section may be detected by autoconf.
      - FREEZE_PROTECTION
    supported_swing_modes:      # Optional
      - VERTICAL
      - HORIZONTAL
      - BOTH
    outdoor_temperature:        # Optional. Outdoor temperature sensor (may display incorrect values after long inactivity).
      name: Temp
    power_usage:                # Optional. Power usage sensor (only for devices that support this feature).
      name: Power
    humidity_setpoint:          # Optional. Indoor humidity sensor (only for devices that support this feature).
      name: Humidity
```

## Configuration variables

- **uart_id** (*Optional*, [ID](/guides/configuration-types/#id)): Manually specify the ID of the [Uart](/components/uart/) if you want
  to use multiple UART buses.

- **transmitter_id** (*Optional*, [ID](/guides/configuration-types/#id)): Defined and used automatically when using [Remote Transmitter](/components/remote_transmitter/) component for IR commands transmit.
- **display_control** (*Optional*, string): How [`midea_ac.display_toggle`](#midea_ac-display_toggle-action) reaches
  the appliance. `UART` always sends the UART request. `IR` always uses the
  [Remote Transmitter](/components/remote_transmitter/), so one has to be configured. `AUTO` sends the UART request
  when the appliance reports display control, or when no remote transmitter is configured, and uses IR otherwise.
  Defaults to `AUTO`.
- **period** (*Optional*, [Time](/guides/configuration-types/#time)): Minimal period between requests to the appliance. Defaults to `1s`.
- **timeout** (*Optional*, [Time](/guides/configuration-types/#time)): Request response timeout until next request attempt. Defaults to `2s`.
- **num_attempts** (*Optional*, int): Number of request attempts between 1 and 5 inclusive. Defaults to `3`.
- **autoconf** (*Optional*, boolean): Get capabilities automatically. Allows you not to manually define most of the capabilities of the appliance.
  Defaults to `True`.

- **beeper** (*Optional*, boolean): Beeper feedback on command. Defaults to `False`.
- **supported_modes** (*Optional*, list): List of supported modes. Possible values are: `HEAT_COOL`, `COOL`, `HEAT`, `DRY`, `FAN_ONLY`.
- **custom_fan_modes** (*Optional*, list): List of supported custom fan modes. Possible values are: `SILENT`, `TURBO`.
- **supported_presets** (*Optional*, list): List of supported presets. Possible values are: `ECO`, `BOOST`, `SLEEP`.
- **custom_presets** (*Optional*, list): List of supported custom presets. Possible values are: `FREEZE_PROTECTION`.
- **supported_swing_modes** (*Optional*, list): List of supported swing modes. Possible values are: `VERTICAL`, `HORIZONTAL`, `BOTH`.
- **outdoor_temperature** (*Optional*): The information for the outdoor temperature
  sensor.

  - All options from [Sensor](/components/sensor).
- **power_usage** (*Optional*): The information for the current power consumption
  sensor.

  - All options from [Sensor](/components/sensor).
- **humidity_setpoint** (*Optional*): The information for the humidity indoor
  sensor (experimental).

  - All options from [Sensor](/components/sensor).
- All other options from [Climate](/components/climate/#config-climate).

## Sensor

The `midea` sensor platform reads values the appliance reports only on request: compressor and refrigerant circuit
data, fan speeds, energy, measured humidity, outdoor unit power and louver angles. Each configured sensor adds a query
that takes turns with the status query, so with any of them configured the climate state refreshes every second
request (`period` apart). An appliance that does not report a value leaves its sensor unknown.

```yaml
# Example configuration entry
climate:
  - platform: midea
    id: midea_ac
    name: Midea Climate

sensor:
  - platform: midea
    midea_id: midea_ac
    energy_format: BCD
    error_code:
      name: Error Code
    indoor_humidity:
      name: Indoor Humidity
    compressor_frequency:
      name: Compressor Frequency
    indoor_fan_speed:
      name: Indoor Fan Speed
    total_energy:
      name: Total Energy
```

### Configuration Variables

- **midea_id** (*Optional*, [ID](/guides/configuration-types/#id)): The `midea` climate to read from. Only needed with
  more than one.
- **energy_format** (*Optional*, string): How the appliance encodes `total_energy`, `current_energy` and
  `real_time_power`. One of `BCD` (most appliances) or `BINARY`. If the values look wrong, try the other one. Defaults
  to `BCD`.
- **error_code** (*Optional*): The appliance error code; `0` means no error. All options from
  [Sensor](/components/sensor/).
- **compressor_frequency** (*Optional*): Compressor frequency in Hz. All options from [Sensor](/components/sensor/).
- **compressor_target_frequency** (*Optional*): Compressor target frequency in Hz. All options from
  [Sensor](/components/sensor/).
- **compressor_current** (*Optional*): Compressor current in A. All options from [Sensor](/components/sensor/).
- **compressor_voltage** (*Optional*): Compressor voltage in V. All options from [Sensor](/components/sensor/).
- **indoor_coil_temperature** (*Optional*): Indoor heat exchanger temperature (T2) in °C. All options from
  [Sensor](/components/sensor/).
- **outdoor_coil_temperature** (*Optional*): Outdoor heat exchanger temperature (T3) in °C. All options from
  [Sensor](/components/sensor/).
- **discharge_temperature** (*Optional*): Compressor discharge pipe temperature (TP) in °C. All options from
  [Sensor](/components/sensor/).
- **indoor_fan_speed** (*Optional*): Indoor fan speed in RPM. All options from [Sensor](/components/sensor/).
- **indoor_fan_target_speed** (*Optional*): Indoor fan target speed in RPM. All options from
  [Sensor](/components/sensor/).
- **total_energy** (*Optional*): Total energy use in kWh. All options from [Sensor](/components/sensor/).
- **current_energy** (*Optional*): Energy use of the current run in kWh. All options from [Sensor](/components/sensor/).
- **real_time_power** (*Optional*): Power use in W, from the same report as the energy values. All options from
  [Sensor](/components/sensor/).
- **indoor_humidity** (*Optional*): Measured indoor humidity in %, on appliances with a humidity sensor. The climate's
  `humidity_setpoint` sensor is the humidity setpoint, not this measurement. All options from
  [Sensor](/components/sensor/).
- **outdoor_fan_speed** (*Optional*): Outdoor fan speed in RPM. All options from [Sensor](/components/sensor/).
- **outdoor_unit_power** (*Optional*): Power use of the outdoor unit in W. All options from
  [Sensor](/components/sensor/).
- **horizontal_louver_angle** (*Optional*): Horizontal louver angle in degrees. All options from
  [Sensor](/components/sensor/).
- **vertical_louver_angle** (*Optional*): Vertical louver angle in degrees. All options from
  [Sensor](/components/sensor/).

- **water_pump** (*Optional*): On while the condensate pump runs. All options from
  [Binary Sensor](/components/binary_sensor/).
- **filter_alert** (*Optional*): On when the appliance asks for the filter to be cleaned. All options from
  [Binary Sensor](/components/binary_sensor/).
- **display** (*Optional*): On while the appliance display is lit. All options from
  [Binary Sensor](/components/binary_sensor/).
- **follow_me** (*Optional*): On while the appliance uses the FollowMe temperature. All options from
  [Binary Sensor](/components/binary_sensor/).
- **self_cleaning** (*Optional*): On while the self clean cycle runs. All options from
  [Binary Sensor](/components/binary_sensor/).

## Switch

The `midea` switch, select, number and button platforms control settings the climate entity does not cover. They are
not detected from the appliance, so configure only the ones your appliance supports. A change is sent right away and
the entity changes when the appliance confirms it, so a setting the appliance refuses keeps its old value. The climate's
`beeper` setting also applies to these changes.

```yaml
# Example configuration entry
switch:
  - platform: midea
    midea_id: midea_ac
    purifier:
      name: Purifier
    jet_cool:
      name: Jet Cool
```

### Configuration Variables

- **midea_id** (*Optional*, [ID](/guides/configuration-types/#id)): The `midea` climate to control. Only needed with
  more than one.
- **purifier** (*Optional*): Ionizer / air purifier. All options from [Switch](/components/switch/).
- **fahrenheit** (*Optional*): Show °F on the appliance display. All options from [Switch](/components/switch/).
- **jet_cool** (*Optional*): Jet cool (flash). All options from [Switch](/components/switch/).
- **breeze_away** (*Optional*): Breeze away, on appliances without `breeze_mode`. All options from
  [Switch](/components/switch/).
- **breezeless** (*Optional*): Breezeless, on appliances without `breeze_mode`. All options from
  [Switch](/components/switch/).
- **out_silent** (*Optional*): Outdoor unit silent mode. All options from [Switch](/components/switch/).
- **ieco** (*Optional*): iECO mode. All options from [Switch](/components/switch/), and:

  - **ieco_number** (*Optional*, int): The iECO number the appliance expects. Defaults to `1`.

- **sound** (*Optional*): The appliance sound setting. All options from [Switch](/components/switch/).

The switches show the state the appliance reports; their `restore_mode` defaults to `DISABLED`. `purifier` and
`fahrenheit` are ignored until the appliance has sent its first status report.

## Select

```yaml
# Example configuration entry
select:
  - platform: midea
    midea_id: midea_ac
    vertical_swing_angle:
      name: Vertical Swing Angle
    rate_select:
      name: Rate Select
      levels: 5
```

### Configuration Variables

- **midea_id** (*Optional*, [ID](/guides/configuration-types/#id)): The `midea` climate to control. Only needed with
  more than one.
- **aux_heat_mode** (*Optional*): Electric auxiliary heater: `Off`, `Aux Heat` or `Aux Only`. Ignored until the
  appliance has sent its first status report. All options from [Select](/components/select/).
- **vertical_swing_angle** (*Optional*): Fixed vertical louver position: `Off`, `Position 1` to `Position 5`. All
  options from [Select](/components/select/).
- **horizontal_swing_angle** (*Optional*): Fixed horizontal louver position: `Off`, `Position 1` to `Position 5`. All
  options from [Select](/components/select/).
- **cascade** (*Optional*): Cascade (wind around) airflow: `Off`, `Up` or `Down`. All options from
  [Select](/components/select/).
- **fresh_air** (*Optional*): Fresh air fan: `Off`, `Low`, `Medium`, `High` or `Boost`. All options from
  [Select](/components/select/).
- **rate_select** (*Optional*): Power limit (gear). All options from [Select](/components/select/), and:

  - **levels** (*Optional*, int): The levels the appliance has: `2` (`Off`, `75%`, `50%`) or `5` (`Off`, `Level 5` to
    `Level 1`). Defaults to `5`.

- **breeze_mode** (*Optional*): `Off`, `Breeze Away`, `Breeze Mild` or `Breezeless`, on appliances with breeze
  control. All options from [Select](/components/select/).
- **breeze_away_direction** (*Optional*): `Off`, `Up` or `Down`. All options from [Select](/components/select/).

When the appliance reports a swing angle or fresh air speed between two options, for example one set with the remote,
the select shows the nearest option. Any other reported value without an option is logged as a warning and leaves the
select unchanged; with `rate_select`, this usually means `levels` does not match the appliance.

## Number

```yaml
# Example configuration entry
number:
  - platform: midea
    midea_id: midea_ac
    fan_speed:
      name: Fan Speed
```

### Configuration Variables

- **midea_id** (*Optional*, [ID](/guides/configuration-types/#id)): The `midea` climate to control. Only needed with
  more than one.
- **fan_speed** (*Optional*): Fan speed in percent (1-100), on appliances with stepless fan control. While it is set to
  a value other than a preset, the climate shows the fan mode as Auto; while the fan runs on auto, the number is
  unknown. All options from [Number](/components/number/).
- **target_humidity** (*Optional*): Humidity setpoint in percent (30-90) for the dry modes. All options from
  [Number](/components/number/).

Both are ignored until the appliance has sent its first status report.

## Automations

### `midea_ac.power_on` Action

This action turn on power. The mode and preset will be restored to the last state before turned off.

```yaml
on_...:
  then:
    - midea_ac.power_on:
```

### `midea_ac.power_off` Action

This action turn off power.

```yaml
on_...:
  then:
    - midea_ac.power_off:
```

### `midea_ac.power_toggle` Action

This action toggle the power state. Identical to pressing the power button on the remote control.

```yaml
on_...:
  then:
    - midea_ac.power_toggle:
```

### `midea_ac.follow_me` Action

This action transmits an IR FollowMe command telling the air conditioner a more accurate
room temperature value to be used instead of the internal indoor unit sensor.

```yaml
on_...:
  then:
    - midea_ac.follow_me:
        temperature: !lambda "return x;"
        use_fahrenheit: false
        beeper: false
```

Configuration variables:

- **temperature** (**Required**, float, [templatable](/automations/templates)):
  Sets the value of an internal temperature sensor. The value will be **clamped** to the range:

  - *0 °C to 37 °C* when `use_fahrenheit` is `false`.
  - *32 °F to 99 °F* when `use_fahrenheit` is `true`.

- **use_fahrenheit** (*Optional*, boolean, [templatable](/automations/templates)):
  Specifies if the `temperature` value is in Fahrenheit. When set to `true`, the temperature is parsed and sent in Fahrenheit. Defaults to `false` (Celsius).

- **beeper** (*Optional*, boolean, [templatable](/automations/templates)):
  Sets beep on update. Defaults to `false`.

### `midea_ac.display_toggle` Action

This action toggles the display of the appliance over UART or the [Remote Transmitter](/components/remote_transmitter/),
as chosen by `display_control`. Many appliances, Mundoclima and Rotenso among them, accept the UART toggle without
reporting display control, so in `AUTO` they get IR whenever a remote transmitter is configured. If such a unit
ignores the toggle, set `display_control: UART`.

```yaml
on_...:
  then:
    - midea_ac.display_toggle:
```

### `midea_ac.swing_step` Action

This action adjust the louver by one step. [Remote Transmitter](/components/remote_transmitter/) required.

```yaml
on_...:
  then:
    - midea_ac.swing_step:
```

### `midea_ac.beeper_on` Action

This action turn on beeper feedback.

```yaml
on_...:
  then:
    - midea_ac.beeper_on:
```

### `midea_ac.beeper_off` Action

This action turn off beeper feedback.

```yaml
on_...:
  then:
    - midea_ac.beeper_off:
```

## Additional control options using IR commands

It is possible to use the FollowMe function and some other features available only through IR commands.
Below is an example of how to send FollowMe commands with the values of your sensor using the [Remote Transmitter](/components/remote_transmitter/)
component, as well as toggle the LED display over IR.

```yaml
# Example configuration entry

remote_transmitter:
  pin: GPIO13                       # For iot-uni-stick.
  carrier_duty_percent: 100%        # 50% for IR LED, 100% for direct connect to TSOP IR receiver output.

sensor:
  - platform: homeassistant
    entity_id: sensor.room_sensor   # Sensor from HASS
    internal: true
    filters:
      - throttle: 10s
      - heartbeat: 2min             # Maximum interval between updates.
      - debounce: 1s
    on_value:
      midea_ac.follow_me:
        temperature: !lambda "return x;"
        beeper: false               # Optional. Beep on update.

# template buttons for sending display control command and swing step actions
button:
  - platform: template
    name: Display Toggle
    icon: mdi:theme-light-dark
    on_press:
      midea_ac.display_toggle:
  - platform: template
    name: Swing Step
    icon: mdi:tailwind
    on_press:
      midea_ac.swing_step:
```

## Example of Beeper Control Using a Switch

```yaml
switch:
  - platform: template
    name: Beeper
    icon: mdi:volume-source
    optimistic: true
    turn_on_action:
      midea_ac.beeper_on:
    turn_off_action:
      midea_ac.beeper_off:
```
