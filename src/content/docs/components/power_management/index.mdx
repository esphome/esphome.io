The `power_management` component configures the power-saving behaviour of the device. Each supported
platform registers its own `platform:` entry under this component, with its own configuration options.

```yaml
# Example configuration entry
power_management:
  - platform: ...
```

## Configuration Variables

- **platform** (**Required**, string): One of the supported [platforms](#platforms).
- **id** (*Optional*, [ID](/guides/configuration-types/#id)): Manually specify the ID used for code
  generation.

## Platforms

- [**ESP32**](/components/power_management/esp32_power_management/): Dynamic frequency scaling and automatic
  light sleep on the ESP32 family.
