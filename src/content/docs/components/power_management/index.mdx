The `power_management` component configures power-saving behavior for the device. Each supported
platform registers its own `platform:` entry under this component, with its own set of configuration
options.

## Base Power Management Configuration

```yaml
# Example configuration entry
power_management:
  - platform: ...
```

<span id="config-power-management"></span>

**Configuration variables:**

- **platform** (**Required**, [platform](#platforms-power-management)): One of the supported Power
  Management [Platforms](#platforms-power-management).
- **id** (*Optional*, [ID](/guides/configuration-types#id)): Manually specify the ID used for code
  generation.

<span id="platforms-power-management"></span>

## Platforms

- [**ESP32**](/components/power_management/esp32_pm/) Dynamic frequency scaling and automatic Light
  Sleep for ESP-IDF
