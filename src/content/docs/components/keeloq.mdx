---
title: "KeeLoq Remote"
description: "Instructions for sending KeeLoq rolling codes from a key and a stored counter."
---

The `keeloq` component acts as a KeeLoq remote control: it computes the encrypted hopping code from a
manufacturer key, a serial number and a counter, and sends it through a
[Remote Transmitter](/components/remote_transmitter/). The supported type is `jarolift`, for Jarolift TDEF shutter
motors. For codes that are already encrypted, use
[`remote_transmitter.transmit_keeloq`](/components/remote_transmitter/#remote_transmitter-transmit_keeloq) instead.

> [!WARNING]
> The manufacturer key is secret: keep it in `secrets.yaml`. Anyone with the key and a serial number can control the
> receivers that learned it.

## Configuration

```yaml
# Example configuration entry
keeloq:
  - id: shutter_remote
    type: jarolift
    manufacturer_key: !secret jarolift_manufacturer_key
    serial: 0x1234500
```

## Configuration Variables

- **id** (*Optional*, [ID](/guides/configuration-types/#id)): The ID of this remote, used by the actions.
- **type** (**Required**, enum): How the device key, the hopping code and the pairing sequence are built. One of
  `jarolift`.
- **manufacturer_key** (**Required**, int): The 64-bit manufacturer key. A key given as two 32-bit halves is written
  MSB first: `0x<MSB><LSB>`.
- **serial** (**Required**, int): The 28-bit serial number this remote sends. The motor learns it with
  [`keeloq.learn`](#keeloq-learn-action).

## Counter

The 16-bit counter is reserved in flash in blocks of 8 before it is sent, so the remote writes to flash once every
8 frames. After a reboot it continues after the reserved block: no code repeats and the jump is at most 8. The
counter is stored under the type and the serial, so a firmware update keeps it. After a flash erase, set it with
`keeloq.set_counter` or pair again.

## Actions

### `keeloq.send` Action

This [action](/automations/actions#all-actions) sends the next frame of the remote.

```yaml
on_...:
  - keeloq.send:
      id: shutter_remote
      command: up
      channels: [1, 2, 3, 4]
```

- **id** (**Required**, [ID](/guides/configuration-types/#id)): The ID of the remote.
- **command** (**Required**, string or int, [templatable](/automations/templates)): A name from
  [Command Names](#command-names) or the 4-bit button code.
- **channels** (**Required**, list or int, [templatable](/automations/templates)): A list such as `[1, 2, 3, 4]` of
  channels `1` to `16`, or the 16-bit mask they make (bit 0 is channel 1, so `0x000F` is channels 1 to 4). A
  lambda returns the mask.
- **repeat** (*Optional*): How often the frame is sent. Defaults to the count in [Command Names](#command-names),
  without a pause.
- All other options from
  [Remote Transmitter Actions](/components/remote_transmitter/#remote_transmitter-transmit_action).

### Command Names

| Name | Code | Sent |
|---|---|---|
| `up` | `0x8` | 2× |
| `down` | `0x2` | 2× |
| `stop` | `0x4` | 2× |
| `learn` | `0xA`, up and down together | 2× |
| `shade` | `0x4`, stop held: moves to the shade position | 20× |

A button code without a name is sent 2×. `learn` sends only the code `0xA`; the pairing sequence is
[`keeloq.learn`](#keeloq-learn-action).

### `keeloq.learn` Action

This [action](/automations/actions#all-actions) pairs the remote: it sends up and down together, one second later
stop, each twice. Put the motor into learn mode as its manual describes, then run the action within 5 seconds. The
motor vibrates when it has learned the serial; a hand remote paired before keeps working.

```yaml
on_...:
  - keeloq.learn:
      id: shutter_remote
      channels: [1]
```

- **id** (**Required**, [ID](/guides/configuration-types/#id)): The ID of the remote.
- **channels** (**Required**, list or int, [templatable](/automations/templates)): The channels to pair.
- **legacy** (*Optional*, boolean, [templatable](/automations/templates)): Sends the single command `0x1` that motors
  made before 2010 learn from. Try `true` if the motor does not vibrate. Defaults to `false`.
- **transmitter_id** (*Optional*, [ID](/guides/configuration-types/#id)): The remote transmitter to send with.

### `keeloq.set_counter` Action

This [action](/automations/actions#all-actions) sets the counter of the next frame and stores it at once.

```yaml
on_...:
  - keeloq.set_counter:
      id: shutter_remote
      counter: 0x1000
```

- **id** (**Required**, [ID](/guides/configuration-types/#id)): The ID of the remote.
- **counter** (**Required**, int, [templatable](/automations/templates)): The counter of the next frame.
