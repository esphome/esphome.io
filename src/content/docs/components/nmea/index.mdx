The NMEA component creates a virtual UART bus that provides NMEA (National Marine Electronics Association) data streams. This allows components like [GPS](/components/gps) to receive location and navigation data.

NMEA is a standard protocol used by GPS receivers and other marine electronics to transmit data. The protocol uses ASCII sentences that begin with a dollar sign ($) and contain comma-separated values.

## Platforms

The following platforms are available for NMEA:

- [Modem NMEA Platform](/components/nmea/modem) - Provides NMEA data from a cellular modem
