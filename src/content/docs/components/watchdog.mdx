The `watchdog` component is used to change the timeout of the task watchdog timer for the main loop 
from the default setting during ESPHome initialization.

```yaml
# Example configuration entry
watchdog:
  timeout: 5sec

switch:
  - platform: template
    name: "Extend watchdog timeout"
    optimistic: true
    restore_mode: ALWAYS_OFF
    turn_on_action:
      then:
        - logger.log: "Set Watchdog Timeout to 25 seconds"
        - watchdog.set_timeout: 25sec
    turn_off_action:
      then:
        - logger.log: "Set Watchdog Timeout to 5 seconds"
        - watchdog.set_timeout:
            timeout: 5sec
```

## Configuration variables

- **timeout** (*Optional*, [Time](/guides/configuration-types#time)): set task watchdog timeout.

## `watchdog.set_timeout` Action

This [action](/automations/actions#all-actions) sets task watchdog timeout.

```yaml
on_...:
  then:
    - watchdog.set_timeout:
        timeout: 10sec
  # Short form
    - watchdog.set_timeout: 10sec
```

#### Configuration variables

- **timeout** (*Required*, [Time](/guides/configuration-types#time)): set task watchdog timeout.
