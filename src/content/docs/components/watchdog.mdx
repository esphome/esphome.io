The `watchdog` component is used to change the timeout of the task watchdog timer for the main loop 
for esp-idf and rasp2040 from the default setting during ESPHome initialization.

```yaml
# Example configuration entry
watchdog:
  timeout: 60sec
```

## Configuration variables

- **timeout** (*Optional*, [Time](/guides/configuration-types#time)): set main loop task watchdog timeout.
