The `cst328` touchscreen platform allows using the Hynitron CST328 and CST3240 touch screen controllers with
ESPHome. The [I²C](/components/i2c) is required to be set up in your configuration for this touchscreen to work.

The CST328 is used in the Waveshare ESP32-S3 Touch LCD 2.8 board. The CST3240 is used on some industrial (CAN/RS485)
ESP32-S3 panels from PanelLan / Wireless Tag.

## Base Touchscreen Configuration

```yaml
# Example configuration entry
touchscreen:
  platform: cst328
  id: my_touchscreen
  interrupt_pin: GPIOXX
```

### Configuration variables

- **id** (*Optional*, [ID](/guides/configuration-types/#id)): Manually set the ID of this touchscreen.
- **model** (*Optional*, string): The controller chip, `CST328` (default) or `CST3240`. The default I²C address is
  `0x1A` for the CST328 and `0x5A` for the CST3240.
- **interrupt_pin** (*Optional*, [Pin Schema](/guides/configuration-types/#pin-schema)): The touch detection pin.
- **reset_pin** (*Optional*, [Pin Schema](/guides/configuration-types/#pin-schema)): The chip reset pin.

- All other options from [Touchscreen](/components/touchscreen/#config-touchscreen).

## Binary Sensor

In addition to touch areas on the screen configured through the [Touchscreen](/components/touchscreen/#config-touchscreen) component,
a binary sensor can be configured to react to touching anywhere on the screen.

```yaml
# Example configuration entry
binary_sensor:
  - platform: cst328
    name: "Screen touched"
```

### Configuration variables

- **cst328_id** (*Optional*, [ID](/guides/configuration-types/#id)): Manually specify the ID of the touchscreen.

- All other options from [Binary Sensor](/components/binary_sensor/#config-binary_sensor).

### Sample config for the Waveshare ESP32-S3 Touch LCD 2.8 board

```yaml
i2c:
  sda: GPIO6
  scl: GPIO7

touchscreen:
  - platform: cst328
    id: my_touchscreen
    interrupt_pin: GPIO8
    reset_pin: GPIO17
```

### Sample config for a PanelLan / Wireless Tag ESP32-S3 panel (CST3240)

```yaml
i2c:
  sda: GPIO09
  scl: GPIO03
  frequency: 400kHz

touchscreen:
  - platform: cst328
    model: CST3240
    id: my_touchscreen
    display: display0
    interrupt_pin: GPIO42
```
