The TCA9548A component allows you to use TCA9548A as a I²C multiplexer
([datasheet](https://www.ti.com/lit/ds/symlink/tca9548a.pdf),
[AdaFruit](https://learn.adafruit.com/adafruit-tca9548a-1-to-8-i2c-multiplexer-breakout)) in ESPHome. It uses [I²C Bus](/components/i2c/) for communication.

Once configured, you can use any of the 8 channels (TCA9548A) as separated channels for your projects.
Each channel acts as a virtual I²C bus for the connected components, and can be set to a different frequency than
the main I²C bus.

Please note that the main (upstream) I²C bus frequency is temporarily changed to the frequency of the active channel,
so the devices on the main bus must be able to gracefully handle all selected channel speeds!
This is usually not a problem if the channels are all the same or slower than the main bus.

```yaml
# The main I²C bus; its frequency applies to channels without one of their own
i2c:
  id: i2c0
  frequency: 400 kHz

# Example configuration entry
tca9548a:
  - address: 0x70
    i2c_id: i2c0
    channels:
      - bus_id: multiplex0channel0
        channel: 0
      - bus_id: multiplex0channel1
        channel: 1
        frequency: 100 kHz

# Individual I2C Devices
sensor:
  - platform: bmp280
    i2c_id: multiplex0channel1
```

## Configuration variables

- **id** (*Optional*, [ID](/guides/configuration-types/#id)): The id to use for this TCA9548A component.

- **address** (*Optional*, int): Manually specify the I²C address of the multiplexer.
  Defaults to `0x70`.

- **i2c_id** (*Optional*, [ID](/guides/configuration-types/#id)): The upstream I²C bus to use. Required when more than one I²C bus
  is configured.

- **channels** (*Optional*): The virtual I²C bus channels

  - **bus_id** (**Required**, [ID](/guides/configuration-types/#id)): The id to use for this virtual I²C bus.

  - **channel** (**Required**): The channel (0-7) to use for this virtual I²C bus.

  - **frequency** (*Optional*, frequency): The frequency for this virtual I²C bus.
    Defaults to the main bus frequency.
