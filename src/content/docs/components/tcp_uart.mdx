This component allows ESPHome to use a TCP connection as a [UART bus](/components/uart/). Bytes received on the
socket can be read like UART data, and bytes written to the UART are sent to the socket. Any component that has a
`uart_id` option can use it.

> [!NOTE]
> There is no `baud_rate` option. The connection is a TCP socket, not a serial line.

```yaml
# Example configuration entry
tcp_uart:
  - id: tcp_uart_1
    host: 192.0.2.10
    port: 502

modbus:
  - id: modbus_bus
    uart_id: tcp_uart_1
```

## Configuration variables

- **id** (*Optional*, [ID](/guides/configuration-types#id)): Manually specify the ID used for code generation. Use
  this ID as `uart_id` in other components.
- **host** (**Required**, string): The host to connect to. An IP address or a hostname.
- **port** (**Required**, int): The TCP port to connect to.
- **reconnect_interval** (*Optional*, [Time](/guides/configuration-types#time)): The time to wait before connecting
  again after a failed or closed connection. Defaults to `5s`.
- **connected** (*Optional*): A [binary sensor](/components/binary_sensor/) that reports whether the TCP connection
  is established.
