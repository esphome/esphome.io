The `es7210` platform allows your ESPHome devices to use the ES7210 high performance four channel audio ADC
([datasheet](http://www.everest-semi.com/pdf/ES7210%20PB.pdf)).
This allows attached microphones to be used as a microphone input via [I2S Audio](/components/microphone/i2s_audio/).

The [I²C bus](/components/i2c) is required in your configuration as this is used to communicate with the ES7210.

```yaml
# Example configuration entry
audio_adc:
  - platform: es7210
```

<span id="config-es7210"></span>

## Configuration variables

- **bits_per_sample** (*Optional*, enum): The bit depth of the audio samples. One of `16bit`, `24bit` or `32bit`.
  Defaults to `16bit`.

- **mic_gain** (*Optional*, enum): The gain applied to the ADC microphones. One of `0DB`, `3DB`, `6DB`, `9DB`,
  `12DB`, `15DB`, `18DB`, `21DB`, `24DB`, `27DB`, `30DB`, `33DB`, `34.5DB`, `36DB`, or `37.5DB`.
  Defaults to `24DB`.

- **sample_rate** (*Optional*, positive integer): I2S sample rate. Defaults to `16000`.
- **tdm** (*Optional*, boolean): Enable four-channel time-division multiplexed (TDM) output. Enabling this option
  changes `SDOUT1` from a two-channel I2S output into a four-slot TDM stream containing microphones 1 through 4;
  `SDOUT2` is therefore not needed to receive all four microphones. When disabled, microphones 1 and 2 are output
  on `SDOUT1`, and microphones 3 and 4 are output on `SDOUT2`. Defaults to `false`.
- **address** (*Optional*, int): The I²C address of the driver. Defaults to `0x40`.
- **i2c_id** (*Optional*): The ID of the [I²C bus](/components/i2c) the ES7210 is connected to.
- All other options from [Audio ADC](/components/audio_adc#config-audio_adc).

## Automations

All [Audio ADC Automations](/components/audio_adc#automations-audio_adc) are supported by this platform.

## Configuration Examples

**ESP32 S3 Box 3**:

```yaml
audio_adc:
  - platform: es7210
    id: es7210_adc
    bits_per_sample: 16bit
    sample_rate: 16000

i2s_audio:
  - id: i2s_audio_bus
    i2s_lrclk_pin: GPIO45
    i2s_bclk_pin: GPIO17
    i2s_mclk_pin: GPIO2

microphone:
  - platform: i2s_audio
    id: box_mic
    sample_rate: 16000
    i2s_din_pin: GPIO16
    bits_per_sample: 16bit
    adc_type: external
```

**Four-channel TDM output**:

The following configuration places all four microphone channels into four consecutive TDM slots on `SDOUT1`:

```yaml
i2c:
  - id: i2c_bus
    sda: GPIO8
    scl: GPIO9

audio_adc:
  - platform: es7210
    id: es7210_adc
    i2c_id: i2c_bus
    bits_per_sample: 16bit
    sample_rate: 16000
    tdm: true

i2s_audio:
  - id: tdm_audio_bus
    i2s_lrclk_pin: GPIO10
    i2s_bclk_pin: GPIO12
    i2s_mclk_pin: GPIO13

microphone:
  - platform: i2s_audio
    id: tdm_microphone
    i2s_audio_id: tdm_audio_bus
    i2s_din_pin: GPIO11
    adc_type: external
    sample_rate: 16000
    bits_per_sample: 16bit
    channel: stereo
```

The audio receiver connected to the ES7210 must use the same sample rate and sample width and must be configured
for four TDM slots. The `tdm` option configures the ADC's serial output only; it does not configure the ESP32 I2S
peripheral. The [`i2s_audio` microphone](/components/microphone/i2s_audio/) configuration above shows the clock and
data connections, but that platform exposes at most stereo audio. A TDM-capable receiver component is required to
expose all four microphone slots independently.
