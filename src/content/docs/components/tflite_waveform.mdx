The `tflite_waveform` component runs a model that turns one frame of audio into another, such as a noise
reduction model, on ESP32 with the ESP-IDF framework. It loads `tflite_micro_runtime` in the background, so
the kind is the only YAML entry and `model_type` is not used.

```yaml
tflite_waveform:
  - id: denoiser
    decoder_id: denoiser_output
    model: "models/denoiser.tflite"
```

## Configuration variables

- **id** (*Optional*, [ID](/guides/configuration-types/#id)): The runtime helper for this model. Set it
  when a lambda or another component references the instance.
- **decoder_id** (*Optional*, [ID](/guides/configuration-types/#id)): The output decoder. Set it to read
  the decoded result from a lambda.
- **on_result** (*Optional*, [Automation](/automations/)): Actions to run after a successful inference,
  once the decoder holds the result. Read it through `decoder_id`.
- **model** (**Required**, string or dictionary): The `.tflite` model, resolved by
  `tflite_model_source`: a local path, a `github://` shorthand, an HTTP(S) URL, or a JSON manifest that names
  the model.
- **tensor_arena_size** (*Optional*, bytes): Arena size, as bytes or a suffixed value such as `200KB`. When
  omitted, the size is estimated from the model and probed on the device.
- **debug** (*Optional*, boolean): Enable the diagnostics of `tflite_model_debug` for this instance.
  Defaults to `false`.

## Input and Output

The model needs one input and one output, each `[1, samples]` or `[1, samples, 1]` of type `float32`, `int8`
or `uint8`. A model that carries its state in extra tensors is not supported.

The input is a frame of 16-bit signed PCM samples, scaled to `-1.0`-`1.0` for the model. The decoder converts
the output back to 16-bit samples, saturating values outside that range; `samples()` and `sample_count()`
report them. Cutting the audio into frames and overlapping them is up to the consumer.

```cpp
// `pcm` holds as many int16_t samples as the model's input.
if (id(denoiser)->run(reinterpret_cast<const uint8_t *>(pcm), sample_count * sizeof(int16_t)))
  consume(id(denoiser_output)->samples(), id(denoiser_output)->sample_count());
```

The example reads the result right after `run()`, which suits an instance without `on_result`.
