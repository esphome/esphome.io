The [ESPHome Device Builder](https://github.com/esphome/device-builder-frontend) is
the dashboard you use to create configurations, compile firmware, and install it
onto your devices. You can run it as a Home Assistant app, or as a native desktop
app on macOS, Windows, and Linux. Either way, it bundles its own Python
environment — no manual install required.

Pick your platform below. We'll try to detect it automatically.

<InstallSelector />

## What Happens on First Launch?

The app sets up ESPHome in the background and opens the Device Builder in your
browser. A small icon appears in your system tray for quick access — open the
Device Builder, check for updates, or quit from there.
