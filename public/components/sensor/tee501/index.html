TEE501 Temperature Sensor

The hte501 sensor platform Temperature sensor allows you to use your TEE501 (datasheet, E+E TEE501) sensor with ESPHome. The I²C Bus is required to be set up in your configuration for this sensor to work.

# Example configuration entry
sensor:
  - platform: tee501
    name: "Office Temperature"
    address: 0x48
    update_interval: 60s

Configuration variables

  • address (Optional, int): Manually specify the I²C address of the sensor. Defaults to 0x48.

  • update_interval (Optional, Time): The interval to check the sensor. Defaults to 60s.

  • All other options from Sensor.
