Component/Hub
-------------
.. _ld2410s-component:

The ``LD2410s`` sensor platform allows you to use HI-LINK LD2410s motion and presence sensors with ESPHome.

The :ref:`UART <uart>` is required to be set up in your configuration for this sensor to work, ``parity``, ``stop_bits`` and ``baud_rate`` **must be** respectively ``NONE``, ``1`` and ``115200``.
