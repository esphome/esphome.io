The `t3022` sensor platform allows you to use the Telaire T3022 CO₂ module
with ESPHome over the [I²C Bus](/components/i2c). The default I²C address is
`0x15` (shared with other T67xx-series modules).

{{< img src="t3022.jpg" alt="Telaire T3022 CO₂ sensor module" caption="Amphenol/Telaire T3022 CO₂ module as supplied for OEM installation." width="60.0%" class="align-center" >}}

**Quick facts**

- Typical supply is 5 V (check your exact part number).
- I²C address defaults to `0x15`; avoid conflicts with other T67xx modules.
- Common range is 0–5000 ppm CO₂; consult the datasheet for your variant.

```yaml
# Example configuration entry
i2c:

sensor:
  - platform: t3022
    co2:
      name: "CO2"
    address: 0x15
    update_interval: 60s
```

## Configuration variables

- **co2** (*Optional*): Configuration for the CO₂ sensor. All options from
  [Sensor](/components/sensor).

- **address** (*Optional*, int): I²C address of the sensor. Defaults to `0x15`.

- **update_interval** (*Optional*, [Time](/guides/configuration-types#time)): Polling interval for new measurements.
  Defaults to `60s`.

- **i2c_id** (*Optional*, [ID](/guides/configuration-types#id)): Manually specify the I²C bus to use.

- **id** (*Optional*, [ID](/guides/configuration-types#id)): Manually specify the ID for this component.

> [!NOTE]
> Hardware: The module has an internal 4.7 kΩ pull-up on SDA. You must add an external pull-up on SCL (pin 2), typically 4.7 kΩ. The I²C interface can run at 3.3 V or 5 V logic levels; match the pull-up voltage to your MCU or use level shifting if needed.

## Notes

- Calibration: Uses Automatic Background Logic (ABC). Expect operational accuracy after ~25 hours of continuous operation that includes exposure to ambient (~400 ppm) air; maintain accuracy by allowing at least four ambient exposures within 21 days. Keep the sensor powered for ≥24 hours for ABC to work.
- User recalibration is not recommended. ABC begins adjusting measurements after ~24 hours; if immediate consistency is needed, perform a single-point check with reference gas or a trusted ambient reference.

## Troubleshooting

- If logs show `Communication with T3022 failed`, verify the address (`0x15` by default) and that your pull-ups are present.
- Ensure the module has completed its warm-up period (per datasheet) before trusting initial readings.
- Noise on the I²C lines can cause intermittent `invalid response` errors; reduce bus length or lower the clock speed.
