The `alpha3` component allows you to monitor and control a Grundfos Alpha3 Model B circulator pump over BLE.

This component supports the following features:

**Monitoring (Sensor Platform):**

- flow rate
- head pressure
- power consumption
- speed (RPM)
- voltage
- current

**Control (Button/Select/Text Sensor Platforms):**

- mode switching (AutoAdapt, Constant Pressure, Proportional Pressure, Constant Frequency)
- start/stop pump
- setpoint adjustment (increase/decrease)
- current operating mode display

This component uses the BLE peripheral on an ESP32, so you also need to enable
this component. Please see the {{< docref "/components/ble_client" >}} docs for how to discover the MAC
address of your Alpha3 pump, or you can find the list of paired MAC addresses in
the list of paired Bluetooth devices on your smartphone after using the GO Remote app.

## Configuration entry

```yaml
# Example Configuration
esp32_ble_tracker:

ble_client:
  - mac_address: xx:xx:xx:xx:xx:xx
    id: radiator_pump

sensor:
  - platform: alpha3
    ble_client_id: radiator_pump
    id: my_alpha3
    flow:
      name: "Radiator Pump Flow"
    head:
      name: "Radiator Pump Head"
    speed:
      name: "Radiator Pump Speed"
    power:
      name: "Radiator Pump Power"
    voltage:
      name: "Radiator Pump Voltage"
    current:
      name: "Radiator Pump Current"

# Control features (optional)
select:
  - platform: alpha3
    alpha3_id: my_alpha3
    pump_mode:
      name: "Pump Mode"

button:
  - platform: alpha3
    alpha3_id: my_alpha3
    start_pump:
      name: "Start Pump"
    stop_pump:
      name: "Stop Pump"
    setpoint_up:
      name: "Increase Setpoint"
    setpoint_down:
      name: "Decrease Setpoint"

text_sensor:
  - platform: alpha3
    alpha3_id: my_alpha3
    pump_mode:
      name: "Current Mode"
```

## Sensor Platform

### Configuration variables

- **id** (*Optional*, [ID](/guides/configuration-types#id)): Manually specify the ID used for code generation. Required when using control platforms (select/button/text_sensor).
- **flow** (*Optional*): The estimated volume flow of the medium in `m³/h`.
  All options from [Sensor](/components/sensor).

- **head** (*Optional*): The estimated head (pressure difference generated by the pump) in `m`.
  All options from [Sensor](/components/sensor).

- **speed** (*Optional*): the speed of the pump rotor in `RPM`.
  All options from [Sensor](/components/sensor).

- **power** (*Optional*): The power consumption of the pump in `W`.
  All options from [Sensor](/components/sensor).

- **voltage** (*Optional*): Voltage in `V`.
  All options from [Sensor](/components/sensor).

- **current** (*Optional*): Current in `A`.
  All options from [Sensor](/components/sensor)

## Control Platforms

### Select Platform

The select platform allows you to switch between different pump operating modes.

#### Configuration variables

- **alpha3_id** (**Required**, [ID](/guides/configuration-types#id)): The ID of the alpha3 sensor component.
- **pump_mode** (*Optional*): Select the pump operating mode.
  - **Available modes:**
    - `AutoAdapt` - Automatic adaptation to system requirements
    - `Constant Pressure 1 (Min)` - Constant pressure mode, minimum setting
    - `Constant Pressure 2` - Constant pressure mode, medium setting
    - `Constant Pressure 3 (Max)` - Constant pressure mode, maximum setting
    - `Proportional Pressure 1 (Min)` - Proportional pressure mode, minimum setting
    - `Proportional Pressure 2` - Proportional pressure mode, medium setting
    - `Proportional Pressure 3 (Max)` - Proportional pressure mode, maximum setting
    - `Constant Frequency` - Constant frequency mode
  
  All options from [Select](/components/select).

### Button Platform

The button platform provides actions to control the pump.

#### Configuration variables

- **alpha3_id** (**Required**, [ID](/guides/configuration-types#id)): The ID of the alpha3 sensor component.
- **start_pump** (*Optional*): Button to start the pump.
  All options from [Button](/components/button).

- **stop_pump** (*Optional*): Button to stop the pump.
  All options from [Button](/components/button).

- **setpoint_up** (*Optional*): Button to increase the setpoint value.
  All options from [Button](/components/button).

- **setpoint_down** (*Optional*): Button to decrease the setpoint value.
  All options from [Button](/components/button).

### Text Sensor Platform

The text sensor platform displays the current operating mode of the pump.

#### Configuration variables

- **alpha3_id** (**Required**, [ID](/guides/configuration-types#id)): The ID of the alpha3 sensor component.
- **pump_mode** (*Optional*): Displays the current pump operating mode as text.
  All options from [Text Sensor](/components/text_sensor).

## Notes

> [!WARNING]
> Older pumps like the Alpha2 and Alpha3 Model A are not compatible, as they don't have Bluetooth integrated.
> The Alpha Reader is using a different protocol, so it won't work to connect your Alpha2 with this component.

> [!NOTE]
> The ESP needs to be paired with the pump to read the sensors. If the devices are not paired the wireless indicator on the pump will turn on and off again.
>
> For the initial pairing you have to press the 'Connectivity button' (Wireless symbol) on the pump.
> After the initial pairing the ESP should connect automatically when the pump turns on. When the ESP is connected the blue wireless indicator should be constantly lit.

> [!NOTE]
> The pump can only be connected to one device at a time. If you want to use the GO Remote App, you have to first turn the ESP off.

> [!NOTE]
> When using control features, test in this order:
>
> 1. Try REMOTE mode first (no visible effect, just enables remote control)
> 2. Test AutoAdapt mode (simplest mode change)
> 3. Test Start/Stop buttons
> 4. Test setpoint adjustment last
