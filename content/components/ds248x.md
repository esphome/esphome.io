title: "DS248x 1-Wire Bus Master"
description: "Instructions for setting up DS2482-100, DS2482-800, and DS2484 1-Wire masters in ESPHome."
---

The `ds248x` component allows you to use Analog Devices (formerly Maxim Integrated) DS2482-100, DS2482-800, and DS2484 I²C to 1-Wire bridge chips with ESPHome. These chips are robust 1-Wire masters that handle the timing and electrical requirements of the 1-Wire bus, offloading this task from the ESP.

## Supported Hardware

* **DS2482-100**: Single-channel 1-Wire Master.
* **DS2482-800**: 8-channel 1-Wire Master.
* **DS2484**: Single-channel 1-Wire Master with adjustable timing and active pullup.

## Configuration

To use a DS248x, you first need to configure the [I²C Bus](/components/i2c) and then add the `ds248x` component.

```yaml
# Example for DS2482-100 (Single Channel)
i2c:
  sda: 21
  scl: 22

ds248x:
  address: 0x18

sensor:
  - platform: ds248x
    address: 0x...
    name: "Living Room Temperature"
    # No channel needed for single-channel devices
```

```yaml
# Example for DS2482-800 (8 Channels)
ds248x:
  address: 0x18
  channel_count: 8

sensor:
  - platform: ds248x
    address: 0x...
    channel: 0  # Connect to IO0
    name: "Channel 0 Sensor"
  - platform: ds248x
    address: 0x...
    channel: 7  # Connect to IO7
    name: "Channel 7 Sensor"
```

```yaml
# Example for DS2484 (Advanced Timing)
ds248x:
  address: 0x18
  active_pullup: true
  ds2484_active_pullup_resistance: 500ohm
  ds2484_reset_low_time: 1
  ds2484_master_sample_time: 2
```

## Finding Sensor IDs

To find the addresses of your 1-Wire sensors, simply upload the configuration with the `ds248x` component configured (you don't need to add any `sensor` entries yet).

Open the logs, and when the device boots, it will scan the bus and print the addresses of all found devices:

```text
[I][ds248x:055]: found device 0x8500000526766328 (channel: 0 type: 40)
```

Copy this address (e.g. `0x8500000526766328`) into your configuration.

## Configuration Variables

### Common Options (All Chips)

* **address** (**Optional**, int): The I²C address of the device. Defaults to `0x18`.
* **active_pullup** (**Optional**, boolean): Whether to enable the active pullup (APU) feature. Useful for long lines or heavy loads. Defaults to `false`.
* **strong_pullup** (**Optional**, boolean): Whether to enable the strong pullup (SPU) feature. This is required for some sensors that use parasitic power. If not explicitly set, the component will automatically detect if parasitic power is needed and enable this feature. Defaults to `false` (with auto-detection).
* **overdrive_speed** (**Optional**, boolean): Whether to use 1-Wire Overdrive speed. All devices on the bus must support overdrive. Defaults to `false`.
* **sleep_pin** (**Optional**, [Pin Schema](/guides/configuration-types#config-pin_schema)): A GPIO pin connected to the SLPZ (Sleep) pin of the DS248x. Used to wake the device.
* **bus_sleep** (**Optional**, boolean): If true, puts the 1-Wire bus to sleep when not in use. Defaults to `false`.
* **hub_sleep** (**Optional**, boolean): If true, puts the DS248x chip to sleep when not in use (requires `sleep_pin`). Defaults to `false`.

### DS2482-800 Specific Options

* **channel_count** (**Optional**, int): The number of 1-Wire channels the device provides. Set to `8` for the DS2482-800. Defaults to `1` (for DS2482-100 and DS2484).

### DS2484 Specific Options

These options are only available for the DS2484 chip to fine-tune the 1-Wire timing. See the datasheet for details on the values (0-15).

* **ds2484_active_pullup_resistance** (**Optional**, string): The active pullup resistance. One of `1000ohm` (default) or `500ohm`.
* **ds2484_reset_low_time** (**Optional**, int): Adjusts the Reset Low Time (tRSTL). Value between 0 and 15.
* **ds2484_master_sample_time** (**Optional**, int): Adjusts the Master Sample Time (tMSP). Value between 0 and 15.
* **ds2484_write_0_low_time** (**Optional**, int): Adjusts the Write 0 Low Time (tW0L). Value between 0 and 15.
* **ds2484_recovery_time** (**Optional**, int): Adjusts the Recovery Time (tREC0). Value between 0 and 15.

## Sensor Configuration

Sensors like `ds248x` can be connected to the DS248x.

* **channel** (**Optional**, int): For multi-channel devices (such as the DS2482-800), the channel index (0-7) the sensor is connected to. Required when using a multi-channel DS248x, and should be omitted for single-channel devices (DS2482-100, DS2484). Defaults to `0` for multi-channel devices when not specified.
* **resolution** (**Optional**, int): The resolution of the temperature sensor in bits. Valid values are `9`, `10`, `11`, and `12`. Lower resolutions allow for faster updates (e.g. 94ms for 9-bit vs 750ms for 12-bit). Defaults to `12`.
  *Note:* This setting is ignored for DS18S20 sensors, as they always require a 750ms conversion time.

```yaml
# Example with lower resolution for faster updates
sensor:
  - platform: ds248x
    address: 0x...
    name: "Fast Sensor"
    resolution: 9
```

See [Dallas Temperature Sensor](/components/sensor/dallas_temp) for more details on configuring the sensors.
