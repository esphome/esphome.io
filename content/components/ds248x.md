title: "DS248x 1-Wire Bus Master"
description: "Instructions for setting up DS2482-100, DS2482-800, and DS2484 1-Wire masters in ESPHome."
---

The `ds248x` component allows you to use Analog Devices (formerly Maxim Integrated) DS2482-100, DS2482-800, and DS2484 I²C to 1-Wire bridge chips with ESPHome. These chips are robust 1-Wire masters that handle the timing and electrical requirements of the 1-Wire bus, offloading this task from the ESP.

## Supported Hardware

- **DS2482-100**: Single-channel 1-Wire Master.
- **DS2482-800**: 8-channel 1-Wire Master.
- **DS2484**: Single-channel 1-Wire Master with adjustable timing and active pullup.

## Configuration

To use a DS248x, you first need to configure the [I²C Bus](/components/i2c), then add the `ds248x` hub component, and finally configure one or more `one_wire` buses to connect your sensors.

### Basic Example (DS2482-100 / DS2484)

```yaml
i2c:
  sda: GPIO21
  scl: GPIO22

ds248x:
  id: my_ds248x
  address: 0x18

one_wire:
  - platform: ds248x
    ds248x_id: my_ds248x
    id: onewire_bus

sensor:
  - platform: dallas_temp
    one_wire_id: onewire_bus
    address: 0x1234567890abcdef
    name: "Living Room Temperature"
```

### Multi-Channel Example (DS2482-800)

The DS2482-800 has 8 independent 1-Wire channels. Each channel is configured as a separate `one_wire` platform:

```yaml
ds248x:
  id: my_ds248x
  address: 0x18
  channel_count: 8
  active_pullup: true

one_wire:
  - platform: ds248x
    ds248x_id: my_ds248x
    channel: 0
    id: onewire_ch0
  - platform: ds248x
    ds248x_id: my_ds248x
    channel: 6
    id: onewire_ch6

sensor:
  - platform: dallas_temp
    one_wire_id: onewire_ch0
    address: 0x578295491f64ff28
    name: "Basement Temperature"
  - platform: dallas_temp
    one_wire_id: onewire_ch6
    address: 0xc50113161a25f428
    name: "Attic Temperature"
```

### DS2484 with Advanced Timing

The DS2484 supports adjustable 1-Wire timing parameters for long cable runs or non-standard conditions:

```yaml
ds248x:
  id: my_ds248x
  address: 0x18
  active_pullup: true
  ds2484_active_pullup_resistance: 500ohm
  ds2484_reset_low_time: 1
  ds2484_master_sample_time: 2

one_wire:
  - platform: ds248x
    ds248x_id: my_ds248x
    id: onewire_bus

sensor:
  - platform: dallas_temp
    one_wire_id: onewire_bus
    address: 0x1234567890abcdef
    name: "Temperature Sensor"
```

## Finding Sensor Addresses

To find the addresses of your 1-Wire sensors, upload a configuration with the `ds248x` and `one_wire` components configured (you don't need to add any `sensor` entries yet). Open the logs, and when the device boots, it will scan the bus and print the addresses of all found devices:

```text
[I][one_wire.ds248x:099]: Found 1 devices on channel 0
[I][one_wire.ds248x:102]:   0x578295491f64ff28
```

Copy this address (e.g., `0x578295491f64ff28`) into your sensor configuration.

## Configuration Variables

### Hub Configuration (ds248x)

- **id** (**Optional**, [ID](/components/esphome#config-id)): Manually specify the ID for the hub. Required if you have multiple DS248x chips.
- **address** (**Optional**, int): The I²C address of the device. Defaults to `0x18`.
- **active_pullup** (**Optional**, boolean): Enable the active pullup (APU) feature. Recommended for long lines or heavy loads. Defaults to `false`.
- **strong_pullup** (**Optional**, boolean): Enable the strong pullup (SPU) feature. Required for sensors using parasitic power. If not set, auto-detection is used. Defaults to `false`.
- **overdrive_speed** (**Optional**, boolean): Use 1-Wire Overdrive speed. All devices on the bus must support overdrive. Defaults to `false`.
- **sleep_pin** (**Optional**, [Pin](/components/esphome#config-pin_schema)): GPIO pin connected to the SLPZ (Sleep) pin of the DS248x.
- **bus_sleep** (**Optional**, boolean): Put the 1-Wire bus to sleep when not in use. Defaults to `false`.
- **hub_sleep** (**Optional**, boolean): Put the DS248x chip to sleep when not in use (requires `sleep_pin`). Defaults to `false`.

#### DS2482-800 Specific

- **channel_count** (**Optional**, int): Number of 1-Wire channels. Set to `8` for DS2482-800. Defaults to `1`.

#### DS2484 Specific

These options fine-tune the 1-Wire timing. See the datasheet for values (0-15):

- **ds2484_active_pullup_resistance** (**Optional**, string): Active pullup resistance. One of `1000ohm` (default) or `500ohm`.
- **ds2484_reset_low_time** (**Optional**, int): Adjusts Reset Low Time (tRSTL). Range: 0-15.
- **ds2484_master_sample_time** (**Optional**, int): Adjusts Master Sample Time (tMSP). Range: 0-15.
- **ds2484_write_0_low_time** (**Optional**, int): Adjusts Write 0 Low Time (tW0L). Range: 0-15.
- **ds2484_recovery_time** (**Optional**, int): Adjusts Recovery Time (tREC0). Range: 0-15.

### One-Wire Platform Configuration

- **ds248x_id** (**Required**, [ID](/components/esphome#config-id)): The ID of the `ds248x` hub.
- **id** (**Optional**, [ID](/components/esphome#config-id)): The ID for this 1-Wire bus. Required if connecting sensors.
- **channel** (**Optional**, int): For DS2482-800, the channel index (0-7). Defaults to `0`.

## Sensor Configuration

Use the [Dallas Temperature Sensor](/components/sensor/dallas_temp) platform to read temperature from DS18B20, DS18S20, DS1822, and similar sensors connected via the DS248x bus:

```yaml
sensor:
  - platform: dallas_temp
    one_wire_id: onewire_bus
    address: 0x1234567890abcdef
    name: "Temperature Sensor"
    resolution: 12
```

- **one_wire_id** (**Required**, [ID](/components/esphome#config-id)): The ID of the `one_wire` bus.
- **address** (**Required**, int): The 64-bit address of the sensor.
- **resolution** (**Optional**, int): Temperature resolution in bits (9, 10, 11, or 12). Lower resolution = faster updates. Defaults to `12`.

## Other 1-Wire Devices

Any 1-Wire device that uses the ESPHome [One-Wire Bus](/components/one_wire) interface can be connected to the DS248x, including:

- [Dallas Temperature Sensors](/components/sensor/dallas_temp) (DS18B20, DS18S20, DS1822, MAX31850)
- [DS2438 Battery Monitor](/components/sensor/ds2438)
